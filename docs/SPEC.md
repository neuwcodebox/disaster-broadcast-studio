# 재난방송실 — 요구사항

## 배경과 목표

### 해결할 문제

한국형 EAS 호러는 화면의 화려함보다 평범한 행정 문장과 지도·방송의 변화가 만드는 긴장감이 중요하다. 작품마다 화면과 시간을 코드로 다시 작성하면 AI가 이야기와 연출에 집중하기 어렵고, 실제와 동떨어진 문안은 몰입을 해친다.

### 목표

개발 AI는 이 워크스페이스에서 엔진과 창작 AI용 스킬·참고자료를 개발한다. 사용자는 독립된 빈 워크스페이스에 npm 패키지인 CLI를 설치하고 창작 스킬을 별도로 받아 사용한다. 별도의 창작 AI는 개발 저장소에 의존하지 않고 외부 작품 데이터로 여러 완성 영상을 만든다. 내용과 표현을 바꿀 자유는 유지하되 반복되는 화면·시간·출력 처리는 재사용한다.

### 완성된 모습

새 작품은 엔진 개발 워크스페이스 밖에 작품 데이터와 필요한 자산을 작성하는 것으로 제작한다. AI가 검증 오류를 고치고 특정 프레임과 구간을 확인한 뒤, 유튜브에 올릴 수 있는 완성 영상 파일을 만든다. 특정 괴담이나 사건을 모든 작품의 형식으로 강제하지 않는다.

## 사용자와 핵심 사용 흐름

### AI와 함께 작품 제작

- **사용자·상황:** 제작자가 작품의 소재와 분위기를 정하고, 엔진 개발 AI와 별개의 창작 AI에게 집필·연출·영상 제작을 맡긴다.
- **흐름:** 독립된 빈 워크스페이스 준비 → CLI 별도 설치 및 창작 스킬 수령 → 동봉 참고자료 검토 → 작품 데이터·자산 작성 → 데이터 검증 → 프레임·구간 확인 및 수정 → 전체 영상 출력.
- **관련 요구사항:** F1, F2, F3, F4, F5, F6, F7(선택), N1, N2, N3, N4

### 다른 이야기로 재사용

- **사용자·상황:** 같은 화면 체계로 별개의 작품을 제작한다.
- **흐름:** 워크스페이스 밖 새 작품 폴더 작성 → 사건과 연출 변경 → 엔진 수정 없이 검증·출력.
- **관련 요구사항:** F1, F5, N2

## 범위

<!-- 첫 실사용과 후속 목표를 구분하고, 의도적으로 제외한 범위를 명시한다. -->

### 첫 실사용 범위

F1~F6, N1~N4를 포함하는 전체 제작 흐름을 완성한다. 데이터만 읽는 프로토타입이나 정지 화면으로 완료하지 않는다. 지도·문자·뉴스·시간·음향이 연결된 완성 영상을 출력해야 한다.

### 후속 범위

첫 완성 이후에는 F7의 선택적 스트리밍 채팅과 F3·F4의 지도·음향·후처리 확장을 추가했다. 그 밖의 추가 기능은 별도로 정한다. 현재 범위의 핵심 기능을 임의로 후속으로 미루지 않는다.

### 제외 범위

사람용 GUI 편집기, 실시간 재난 관제, 실제 문자 송출, 뉴스 실시간 수집, 유튜브 업로드 자동화는 포함하지 않는다. 기존 disaster-feed 운영 서비스는 변경하지 않는다. 이 워크스페이스에는 실제 작품 보관 폴더를 두지 않으며, 첫 작품의 줄거리와 러닝타임은 이 도구의 요구사항으로 고정하지 않는다.

## 기능 요구사항

<!-- 각 기능의 동작과 외부에서 확인할 수 있는 수용 기준을 기록한다. -->

### F1. 텍스트 기반 작품과 연출

- **목적:** 이야기 제작과 반복되는 엔진 개발을 분리한다.
- **기대 동작과 경계:** 작품별 사건·기관·지역·문안·뉴스·자산과 등장·퇴장·강조·지도 이동·전환·음향을 텍스트로 지정한다. 동시 사건과 병렬 연출을 지원한다. 독립된 작품이 서로의 데이터를 변경하지 않는다.
- **수용 기준:**
  - 작품의 사건 순서와 연출을 바꾸면 엔진 코드 변경 없이 출력에 반영된다.
  - 존재하지 않는 지역·자산·참조 ID와 실행 불가능한 시간 지정은 위치와 이유를 포함한 검증 오류로 반환한다.
  - 허구 속 기관들의 상충된 주장 자체를 데이터 오류로 거부하지 않는다.

### F2. 영상 시간과 이야기 시간

- **목적:** 관객에게 실제 방송을 지켜보는 감각을 유지하면서 장면 생략도 가능하게 한다.
- **기대 동작과 경계:** 컷 내부의 이야기 시간은 영상 시간과 1:1로 흐른다. 컷 경계에서 이야기 시간을 명시적으로 건너뛸 수 있으며 선택한 전환 동안 기존 시계를 강조한 뒤 숫자가 빠르게 이동하고 도착 시각을 유지한다. 가로 잔상·움직이는 주사선과 중앙의 흐릿한 빠른 재생 아이콘으로 도약을 알리고 도착 시 효과를 거둔다. 이전 정보는 전환 동안 유지한다. 일반 구간은 배속하지 않는다. 사건 발생·공표·화면 수신 시각은 필요할 때 구별한다.
- **수용 기준:**
  - 한 컷의 영상이 60초 진행되면 화면 시계도 60초 진행된다.
  - 다음 컷에 다른 시작 시각을 지정하면 그 경계에서만 시간 이동이 일어난다.
  - 시간 도약 전환은 설명 문구 없이 빠른 재생 아이콘·후처리로 구분되며 시계는 선명하게 유지한다. 이야기 시각이 연속인 컷에는 도약 효과를 표시하지 않는다.
  - 중간 프레임부터 확인해도 처음부터 재생한 동일 프레임과 시계·사건 상태가 일치한다.

### F3. 지도와 방송 화면

- **목적:** 공간적 확산과 여러 정보원을 한 화면에서 읽게 한다.
- **기대 동작과 경계:** 남한 중심의 한반도 지도, 행정구역 강조, 재난문자 이력, 최근 뉴스, 방송 시계를 표시한다. 시나리오가 지정한 문구·색상의 상태 박스와 방송 안내 화면, 사용자 지정 영역·진행선을 지원한다. 문자와 뉴스는 발신자·출처 및 시각을 함께 나타낸다. 지도 확대·이동 및 필요한 지역 보조 화면을 연출 데이터로 제어한다.
- **수용 기준:**
  - 선택한 행정구역이 정확히 강조되고 지도 이동 중에도 방송 정보가 읽힌다. 서로 다른 의미의 지역은 시나리오가 지정한 채우기·윤곽선과 범례로 겹쳐 표현할 수 있다.
  - 문자는 모두 일반 수신 항목으로 쌓여 이전 지시와 비교할 수 있다. 정정 여부는 작성한 본문으로 전달하며 별도 정정 배지나 연결 표시는 생성하지 않는다. 새 문자는 맨 위에 추가되고 기존 문자는 수신 최신순을 유지하며 아래로 이동한다. 과거 이력도 등급 배지·테두리의 고유 색상을 유지한다.
  - 각 문안의 전문을 한 번에 표시하며 중요한 내용을 읽을 시간이 확보된다. 화면에 들어갈 만큼 짧게 작성하도록 길이·줄 수를 검증하고 자동 페이지 분할이나 본문 교체를 하지 않는다.
  - 새 문자의 지정 대상은 채우기가 부드럽게 3회 점멸하며 변경·비활성화를 지원한다. 테두리는 유지한다. 발신자에서 대상 범위를 추측하지 않는다.
  - 뉴스 교체·종료, 문자 수신, 상태의 등장·교체·해제는 짧은 이동·명도 변화로 정보 갱신을 알린다. 새로 등장하거나 바뀐 상태는 진입 후 3회 점멸하고, 유지되는 항목은 다시 강조하지 않는다. 상태 항목의 표시·변경·종료는 시나리오가 정하며 엔진은 경보 종류별 규칙을 추측하지 않는다.
  - 뉴스는 독립된 헤드라인으로 표시되며 재난문자 본문을 자동 복제하지 않는다.
  - km 단위 반경을 지정한 원은 지도 카메라·보조 지도와 같은 지리 좌표로 투영한다. 고정 범위와 반복 확산, 반복 지점 링과 방향을 지정한 점선 흐름을 선택할 수 있으며 페이드·시간 도약·임의 탐색에서도 같은 상태를 복원한다.

### F4. 음향과 시각 연출

- **목적:** 이야기가 요구하는 리듬과 긴장감을 정밀하게 구성한다.
- **기대 동작과 경계:** 음원 시작·종료·볼륨·페이드·침묵과 화면 전환·강조의 시점을 지정한다. 정보 갱신 피드백은 기본 제공하며 변화가 끝나면 정적인 화면으로 돌아온다. 잡음·화면 전체 점멸 등 극적 효과는 작품이 지정한 경우에만 사용한다.
- **수용 기준:**
  - 같은 시점에 지정한 음향과 시각 변화가 같은 영상 프레임을 기준으로 동작한다. 잡음·주사선·색 채널 어긋남·신호 누락·흐림·흑백·비네트·명도 떨림·화면 흔들림·VHS 추적 간섭은 시나리오가 켠 구간에만 적용되고 중첩·페이드·임의 탐색을 지원한다. 후처리 강도 0은 화면을 바꾸지 않으며 암전·송출 종료의 검정을 유지한다. 시간 도약 중에는 유지된 콘텐츠의 후처리도 같은 콘텐츠 프레임에 멈춘다.
  - 상태의 등장·변경·해제, 방송 안내의 시작, 등급별 재난문자 수신에 기본 효과음을 제공하며 이벤트별 사용자 자산·비활성화와 침묵을 지원한다. 뉴스는 기본 무음이며 작품에서 명시한 경우에만 소리를 재생한다. 동일한 상태의 연속 표시는 재알림하지 않는다. 상태음은 화면 교체 시 같은 높이로 짧게 두 번 울리는 전자음이다. 안전안내는 휴대폰 진동형 수신음, 긴급·위급재난은 EAS풍의 불협화음과 반복 패턴으로 단계적으로 더 크고 길게 구분한다.
  - 화면 수축·신호 종료를 데이터로 구성하고 이후 검은 유지 구간을 지정할 수 있다.
  - 컷 전환 때 음향의 유지·종료가 지정대로 처리되고 구간 확인에서도 음향 위치가 맞는다.
  - 로컬 음원은 원본 시작 위치·반복 여부·재생 속도를 지정할 수 있다. 반복과 속도 변경 중에도 영상 시간 기준 길이·페이드·침묵을 유지하고 임의 구간 출력의 음원 위치가 전체 출력과 일치한다.
  - 창작 AI의 Tone.js 모듈을 CLI에서 오프라인 실행해 WAV를 만들고 기존 파일 기반 음향 연출에 연결할 수 있다. 합성 조건과 버전을 보존하며 실패를 성공한 음원으로 보고하지 않는다.

### F5. 검증·미리보기·영상 출력

- **목적:** AI가 사람용 편집기 없이 결과물을 확인하고 완성한다.
- **기대 동작과 경계:** npm 패키지로 제공하는 CLI에서 작품 검증, 로컬 웹 미리보기, 특정 프레임 이미지, 구간 영상, 전체 영상 출력을 제공한다. 오류와 결과 경로를 텍스트로 반환한다. 렌더 없이 특정 프레임의 상태를 조회할 수 있다.
- **수용 기준:**
  - 같은 작품의 프레임·구간·전체 출력이 같은 상태와 연출을 사용한다. 작품 작업공간은 한 명령으로 유효한 YAML·음향 폴더와 함께 생성하며 기존 파일은 덮어쓰지 않는다.
  - 웹 미리보기는 영상 파일 생성 없이 같은 화면·음향을 재생하고 일시정지·임의 탐색·프레임·컷 이동을 제공한다. 시나리오·사용자 지도·참조 음원을 저장하면 재생 위치를 보존해 일시정지 상태로 반영한다. 오류 중에는 마지막 정상 화면을 유지하고 오류를 표시하며, 수정 후 자동 복구한다.
  - 기본 완성 영상은 MP4 형식의 1920×1080, 60fps이며 음향을 포함해 일반 영상 플레이어에서 재생된다.
  - 실패한 출력을 성공한 파일로 보고하지 않고 원인과 해당 작품 위치를 제공한다.

### F6. 창작 AI용 스킬과 참고자료

- **목적:** AI가 상상만으로 행정 문안과 뉴스 문체를 만들지 않게 한다.
- **기대 동작과 경계:** 공식 재난문자 표준문안·민방위 경보 자료, 정부·지자체·현장기관의 법적 권한과 사건별 대응 절차, 뉴스 표현 근거는 배포용 창작 스킬에 동봉하는 정본으로 관리한다. CLI와 별도로 받을 수 있는 스킬과 참고자료를 제공한다. 스킬은 작품 작성·검증·미리보기·출력 방법을 설명하며 개발 AGENTS.md를 창작 지침으로 전용하지 않는다. 인용·요약·창작 예시와 적용 시기·확인 상태를 구분한다. 자료는 작품의 소재나 줄거리를 강제하지 않는다.
- **수용 기준:**
  - 창작 AI가 독립된 빈 워크스페이스에서 설치된 CLI와 받은 스킬·동봉 자료만으로 작품을 작성·검증·출력할 수 있다. 개발 저장소 파일이나 개발용 AGENTS.md를 참조할 필요가 없다.
  - 각 규정 자료에서 출처와 판본 확인 범위를 찾을 수 있다. 실제 발송 문자·뉴스 제목은 기록·보도 시각과 직접 출처를 붙이고, 표준문안·전문·발췌·창작 문안과 구별해 다양한 유형을 참고할 수 있다.
  - 집필 AI가 일반 재난 안내와 민방공 경보, 발령·정정·해제 및 확인된 사실·기관 주장을 구별해 참고할 수 있다.
  - 각 요소의 작성 주체가 가진 정보·환경·권한·목적·수신자를 고려하는 지침을 제공한다. 재난문자의 공적 안내, 뉴스의 절제된 보도, 채팅의 개인 반응을 구별하고, 공개 정보를 스트리밍하는 현황판과 영상을 보는 시청자의 관점에서 표시·음향의 출처와 의미를 검토할 수 있다.
  - 상태바에는 배경시대에 실재하는 공식 체계의 단계·발령 상태만 쓰도록 안내한다. 명칭·단계·발령 주체·적용 범위의 근거를 확인하며, 일반 상황과 개별 조치를 임의의 체계로 만들지 않고 적절한 매체로 전달하도록 구별한다.
  - 재난의 인지·신고·현장조치·상황보고·주민 보호·공개 발표를 담당 주체별로 구성할 수 있는 근거를 제공한다. 법정 권한, 매뉴얼의 운영 절차, 개별 대응 사례를 구별하고, 서로 다른 재난의 격상·대피·복구를 하나의 자동 순서로 만들지 않는다.
  - 화생방공격·테러·전쟁 상황의 군·경·행정·전문기관 대응과 통합방위·동원·국가긴급권의 공개 법적 틀을 제공한다. 평시 사고·민방공경보·군사태세·통합방위사태·헌법상 비상권한의 요건과 적용 범위를 각각 확인할 수 있다.

### F7. 스트리밍 시청자 채팅

- **목적:** 현황판을 스트리밍 중이라는 설정에서 시청자들의 반응과 서로 다른 시각을 보여준다.
- **기대 동작과 경계:** 작품이 지정한 구간에 선택적으로 채팅 패널을 표시하고, 작성한 닉네임·본문·이름 색상을 정해진 시점에 올린다. 실제 플랫폼 연결이나 자동 반응 생성은 포함하지 않는다.
- **수용 기준:**
  - 채팅이 없는 작품은 기존 레이아웃을 유지한다. 채팅이 켜지면 지도·시계·뉴스를 유지하고 재난문자 아래에 별도 공간을 사용한다.
  - 새 메시지는 작성 시각과 함께 아래에 추가되고, 이전 대화는 위로 이동한다. 같은 시점의 메시지는 작품 배열 순서를 유지한다.
  - 패널 구간·컷 경계·시간 도약·임의 탐색에서도 같은 대화를 복원한다. 다른 패널의 대화가 섞이지 않으며 잘못된 패널 참조·구간 밖 메시지를 검증 오류로 반환한다.
  - 문자·뉴스의 기본 알림음을 채팅에 자동 적용하지 않는다. 방송 안내와 화면 효과는 채팅을 포함한 기존 방송 합성 순서를 따른다.

## 비기능 요구사항과 제약

### N1. 절제된 화면과 가독성

- **요구와 적용 범위:** 평범한 방송·관제 화면의 단정함을 기본으로 한다. 장식적인 네온·유리 효과·게임 HUD를 기본 테마로 사용하지 않는다. 지도·문자·뉴스의 위계와 읽을 시간을 확보한다.
- **이유:** 공포의 중심은 내용과 변화이며 과도한 장식은 실제 정보 화면이라는 인상을 깨뜨린다.
- **수용 기준:** 실제 출력 화면에서 한글 누락·충돌·잘림이 없고, 전체 화면과 모바일 가로 전체화면을 가정한 854×480 축소본 모두 핵심 지시를 읽을 수 있다.

### N2. 재현 가능한 독립 제작

- **요구와 적용 범위:** 시간·사건 상태는 영상 프레임으로 결정한다. 출력 중 실시간 API·뉴스·벽시계에 의존하지 않는다. 자산·의존 버전과 필요한 난수 시드를 고정한다.
- **이유:** AI의 부분 수정과 구간 검증이 전체 영상에서도 같은 결과를 내야 한다.
- **수용 기준:** 같은 고정 환경과 입력으로 반복 출력하면 사건·카메라·음향 타이밍이 같고 외부 서비스 없이 제작할 수 있다. 하드웨어가 다른 GPU 사이의 픽셀 단위 일치는 보장 범위가 아니다.

### N3. 로컬 AI 개발과 유지보수

- **요구와 적용 범위:** 공개된 기존 제작·지도 프레임워크를 활용하고 작품 데이터와 엔진 코드를 분리한다. CLI의 오류는 AI가 수정 위치를 파악할 만큼 구체적이어야 한다.
- **이유:** 사람의 반복 GUI 작업이나 매 작품별 엔진 재개발 없이 엔진 개발 AI와 별도의 창작 AI가 각자의 작업을 수행해야 한다.
- **수용 기준:** 로컬에서 텍스트 작성부터 영상 출력까지 수행하고, 서로 다른 작품을 추가할 때 공통 엔진 코드를 수정하지 않는다.

### N4. 출처·사용권과 허구 구분

- **요구와 적용 범위:** 배포 자산의 출처·이용조건을 확인하고 영상의 제목·오프닝 또는 크레딧에 허구임을 명확히 알린다. 실제 긴급 서비스와 연결하지 않는다.
- **이유:** 실제 자료 같은 표현을 활용하더라도 시청자 혼동과 권리 문제를 피해야 한다.
- **수용 기준:** 출력용 자산의 사용권과 게시용 출처 문안을 확인할 수 있고, 완성 영상에 허구 표시가 포함된다.
