# 재난방송실 — 개발 계획

## 현재 상태

<!-- 구현 상태와 검증 범위를 구분하고 다음 작업을 유지한다. -->

- **단계:** 첫 사용 범위 P1~P6·1차 유지보수와 P7 웹 미리보기 구현·검증·npm 배포 완료. P8 선택적 스트리밍 채팅과 P9 모바일 가로 가독성·전문 표시는 로컬 구현·검증 완료.
- **확인 범위:** 프레임 출력, 서로 다른 두 외부 입력의 전체 H.264/AAC MP4, 1080p 60fps, 구간·전체의 시간·카메라·음향, 빈 외부 폴더의 패키지 설치·스킬 복사, 새 연출 기능과 독립 단편 전체 출력, 문자 수신·동시 발송·시간 도약 경계, Tone.js WAV 생성·로컬 샘플·시드 재현·실패 정리, 지도 채우기/윤곽선 중첩·범례, 외부 작품 초기화·충돌 보호, 공통 설치 도구의 격리 Git 설치·갱신, 선택적 화면 후처리, 공통 수신음·수신 지역 강조·시계 전환·상태 진입·송출 종료 연출, 뉴스 교체·문자 이력 이동·상태 교체/해제·방송 안내 전환, 상태·수신 지역 3회 점멸과 과거 문자 등급 색상 유지, 상태·방송 안내·등급별 문자 기본음 5종, 뉴스 기본 무음·명시적 알림음 선택과 음소거·구간 오디오 정합성.
- **실행 환경:** Linux x64, Node.js 24.22.1, Chrome Headless Shell 158, 소프트웨어 WebGL `swangle`. Windows/macOS는 직접 실행하지 않았다.
- **배포:** 웹 미리보기·알림 연출·기본 효과음을 포함한 npm 공개 패키지 [`disaster-broadcast-studio@0.2.0`](https://www.npmjs.com/package/disaster-broadcast-studio/v/0.2.0) 게시 완료. 공개 `latest`·배포물 무결성과 새 폴더의 레지스트리 설치·CLI 초기화·작품 검증을 확인했다. 소스와 `npm pack` 배포물도 제공한다. 독립 작품과 재현 파일은 개발 저장소 밖에서 제작했다. 영상 외부 업로드는 하지 않았다.

## 다음 작업

P8·P9와 작성 주체·시청자 관점의 창작 지침 개정은 로컬 소스 변경이며 공개 npm 0.2.0에는 포함되지 않는다. 다음 배포 시 짧은 문안 한도와 제거한 필드의 계약 변경을 안내하고 패키지 버전·독립 설치를 검증해 포함한다. Windows/macOS의 실행 확인과 영상 외부 업로드는 별도 사용·배포 시점에 진행한다. 후속 기능은 실제 작품 제작 피드백을 기준으로 정한다.
