# 재난방송실 — 개발 계획

## 현재 상태

<!-- 구현 상태와 검증 범위를 구분하고 다음 작업을 유지한다. -->

- **단계:** 첫 사용 범위 P1~P5 구현·로컬 출력 확인 완료.
- **확인 범위:** 프레임 출력, 서로 다른 두 외부 입력의 전체 H.264/AAC MP4, 1080p 60fps, 구간·전체의 시간·카메라·음향, 빈 외부 폴더의 패키지 설치·스킬 복사.
- **실행 환경:** Linux x64, Node.js 24.22.1, Chrome Headless Shell 158, 소프트웨어 WebGL `swangle`. Windows/macOS는 직접 실행하지 않았다.
- **배포:** GitHub main의 소스와 `npm pack` 배포물. 공개 npm 게시·실제 작품 제작·외부 업로드는 하지 않았다.
