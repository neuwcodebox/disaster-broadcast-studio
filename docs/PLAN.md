# 재난방송실 — 개발 계획

## 현재 상태

<!-- 진행 단계, 목표 일정·가용 시간, 장애와 남은 확인 사항을 간결하게 유지한다. 구현 상태와 검증 범위를 구분해 어디까지 확인했는지 밝힌다. -->

- **현재 단계:** 문서 인계. 실제 구현은 시작하지 않았다.
- **목표 일정·가용 시간:** 미정. 이후 사용자의 로컬 환경에서 코딩 AI와 개발한다.
- **확인된 구현·검증:** 하네스 원본의 문서 구조에 계획을 작성하고 재난문자·민방위 규정 전문 및 해당 별표를 확보했다. 프로그램 실행·영상 출력·성능은 아직 검증하지 않았다.
- **주요 장애·미검증:** 로컬 그래픽 환경, 의존 버전·사용권, 작품 데이터 문법이 남아 있다.

## 개발 단계

<!-- 목표 일정과 가용 시간을 고려해 단계의 범위·우선순위를 조정한다. 가까운 작업만 상세화한다. 각 단계에서 구현하거나 검증할 F/N을 `관련 요구사항`에 적고, 완료 기준과 연결한다. 완료한 단계에는 확인 결과 요약과 근거 링크를 남기고, 상세 검증 경위는 작업 이력에 둔다. -->

### P1. 제작 계약과 로컬 렌더 기반

- **목표:** AI가 작성한 데이터를 검증하고, 대상 환경에서 결정적 프레임을 출력할 기반을 마련한다.
- **관련 요구사항:** F1, F2, F5, N2, N3, N4
- **선행 조건:** 로컬 작업 환경 접근.
- **상태:** 예정
- **주요 작업:**
  - [ ] 로컬 OS·GPU와 Remotion/Chromium 지원을 확인하고 의존 버전을 고정한다.
  - [ ] 기존 지도 코드와 데이터 사용조건을 검토하고 재사용 범위를 정한다.
  - [ ] YAML 후보로 사건·컷·연출을 표현해 참조·시간·충돌 검증 규칙을 확정한다.
  - [ ] 프레임 기준 상태 계산과 검증·프레임·구간·전체 출력 진입점을 구성한다.
  - [ ] 컷 시각 점프와 임의 프레임 탐색, 잘못된 참조에 대한 테스트를 작성한다.
- **완료 기준:** 유효한 입력이 대상 로컬 환경에서 지정 프레임으로 출력되고, 잘못된 입력은 위치·이유를 반환한다. F2의 시간·탐색 기준을 통과한다.
- **검증·완료 근거:** 아직 없음.

### P2. 지도·문자·뉴스 방송 화면

- **목표:** 실제 문안 길이와 지도 정보를 소화하는 완성도 있는 화면을 만든다.
- **관련 요구사항:** F3, F5, N1, N2, N4
- **선행 조건:** P1.
- **상태:** 예정
- **주요 작업:** 지도·행정구역·카메라·보조 화면과 문자 이력·뉴스·시계를 통합한다. 한글 장문과 중첩 사건으로 레이아웃·표시 시간을 검증하고 자산 준비를 캡처와 연결한다.
- **완료 기준:** F3의 표시 기준을 충족하고 1080p 및 휴대폰 크기에서 읽을 수 있다. 지도·글꼴 누락을 성공 출력으로 처리하지 않는다.
- **검증·완료 근거:** 아직 없음.

### P3. 연출·음향과 영상 제작 흐름 완성

- **목표:** 정지 화면을 넘어 작품 데이터가 지정하는 전체 연출을 영상으로 완성한다.
- **관련 요구사항:** F1, F2, F4, F5, N1, N2, N3
- **선행 조건:** P1, P2.
- **상태:** 예정
- **주요 작업:** 병렬 연출·음향·침묵·컷 전환을 구현하고 구간 출력과 전체 출력의 일치를 확인한다. 출력 실패와 결과 경로를 CLI에 명확히 표시한다.
- **완료 기준:** 1920×1080 60fps 영상에 음향·지도·문자·뉴스가 동기화되며, 중간 구간에서도 동일한 상태를 재현한다.
- **검증·완료 근거:** 아직 없음.

### P4. 창작 AI용 스킬과 참고자료 배포 준비

- **목표:** 별도의 창작 AI가 엔진 개발 문맥 없이 도구를 사용하고 작품을 작성할 수 있게 한다.
- **관련 요구사항:** F6, N4
- **선행 조건:** 공식 자료 접근. P1~P3과 독립적으로 진행 가능.
- **상태:** 예정
- **주요 작업:** `skills/scenario-writing/references/`의 공식 전문·표준문안과 추가 자료를 정본으로 유지한다. 외부 작품 작성, CLI 검증·부분 출력·수정·완성 출력 절차를 담고 `skills/scenario-writing/SKILL.md`에 지침을 유지하고 구현된 CLI·데이터 계약에 맞춰 완성한다. CLI의 npm 패키징과 별도 스킬 묶음 배포를 준비하고 패키지명·실행명을 정한다. 작품 시대별 적용 범위와 뉴스의 사실·인용 구분을 확인한다. 재배포 자산의 사용조건과 허구 표기 방법을 확정한다.
- **완료 기준:** 개발 저장소가 보이지 않는 독립된 빈 워크스페이스에서 별도로 설치한 CLI와 받은 스킬·자료만으로 작품을 제작할 수 있다. 스킬 묶음의 로컬 링크가 내부에서 모두 해소된다. F6의 근거 추적이 가능하고 확인되지 않은 판본을 현행으로 표시하지 않는다. 사용조건에 맞는 자료와 자산만 배포한다.
- **검증·완료 근거:** 재난문자361호 본문과 별표1·2, 민방위355호 본문·별표 전문 및 원본을 확보했고 판본 출처는 스킬의 references 자료에 연결했다. 작품별 적용과 영상 자산 사용권 검증은 남아 있다.

### P5. 다작품 검증과 사용 안내

- **목표:** 한 작품 전용 구현이 아니라 재사용 가능한 도구로 인계한다.
- **관련 요구사항:** F1, F2, F3, F4, F5, F6, N1, N2, N3, N4
- **선행 조건:** P1~P4.
- **상태:** 예정
- **주요 작업:** 개발 저장소가 보이지 않는 빈 워크스페이스에 npm CLI를 설치하고 스킬을 별도로 받은 뒤, 서로 다른 사건 구성과 연출을 가진 두 검증 데이터 세트로 엔진 수정 없이 출력되는지 확인한다. 이는 기술 검증용이며 실제 작품 두 편의 줄거리를 지금 지정하는 작업은 아니다. 실제 CLI 사용법·환경·출력 예시를 README에 기록한다.
- **완료 기준:** 데이터·자산 교체만으로 두 결과를 출력하고 모든 F/N의 충족 증거를 해당 단계 작업 이력에 남긴다. 완성 영상과 부분 출력·오류 경로를 모두 확인한다.
- **검증·완료 근거:** 아직 없음.
