# 재난방송실 — 개발 계획

## 현재 상태

<!-- 구현 상태와 검증 범위를 구분하고 다음 작업을 유지한다. -->

- **단계:** 첫 사용 범위 P1~P6·1차 유지보수, P7 웹 미리보기, P8 선택적 스트리밍 채팅, P9 모바일 가로 가독성·전문 표시, P10 시간 도약 전환, P11 지도·음향·후처리 확장, P12 범용 지도 그리드와 P4 공적 대응·전시·실제 문안 참고자료 보완의 구현·검증·npm 배포 완료.
- **확인 범위:** 프레임 출력, 서로 다른 두 외부 입력의 전체 H.264/AAC MP4, 1080p 60fps, 구간·전체의 시간·카메라·음향, 빈 외부 폴더의 패키지 설치·스킬 복사, 새 연출 기능과 독립 단편 전체 출력, 문자 수신·동시 발송·시간 도약 경계, Tone.js WAV 생성·로컬 샘플·시드 재현·실패 정리, 지도 채우기/윤곽선 중첩·범례, 외부 작품 초기화·충돌 보호, 공통 설치 도구의 격리 Git 설치·갱신, 선택적 화면 후처리, 공통 수신음·수신 지역 강조·시계 전환·상태 진입·송출 종료 연출, 뉴스 교체·문자 이력 이동·상태 교체/해제·방송 안내 전환, 상태·수신 지역 3회 점멸과 과거 문자 등급 색상 유지, 상태·방송 안내·등급별 문자 기본음 5종, 뉴스 기본 무음·명시적 알림음 선택과 음소거·구간 오디오 정합성.
- **실행 환경:** Linux x64, Node.js 24.22.1, Chrome Headless Shell 158, 소프트웨어 WebGL `swangle`. Windows/macOS는 직접 실행하지 않았다.
- **배포:** 범용 지도 그리드와 작품 작업공간 구조 개선을 포함한 npm 공개 패키지 [`disaster-broadcast-studio@0.5.0`](https://www.npmjs.com/package/disaster-broadcast-studio/v/0.5.0) 게시 성공을 확인했다. 최종 tgz의 패키징·무결성, 독립 설치본의 CLI 초기화·기본 작품 검증·기존 산출물 보호·동봉 README·스킬 내보내기·그리드 생성과 실제 PNG 출력을 확인했다. 소스와 `npm pack` 배포물도 제공한다. 독립 작품과 재현 파일은 개발 저장소 밖에서 제작했다. 영상 외부 업로드는 하지 않았다.
- **그리드:** P12는 셀별 색상·투명도, 시점별 교체·중첩·페이드, 메인·보조 지도 투영, 파일 수정 감지와 창작 AI용 생성 예제를 포함한다. 책임 분리 후 실제 PNG와 1080p60 구간 MP4 120프레임이 변경 전과 픽셀 단위로 일치했다. 0.5.0 배포 시 전체 테스트 83개·타입 검사·빌드와 독립 설치본 사용을 확인했다.
- **작업공간:** P5의 초기화와 창작 안내는 생성 코드·원본을 `src/`, 재생성 가능한 음원·그리드·영상을 `output/`에 모으는 구조로 정리했다. 관련 테스트 12개·빌드·실제 CLI 초기화와 생성 그리드 참조를 확인했다. `.gitignore`는 생성하거나 수정하지 않는다.

## 다음 작업

0.5.0의 npm 게시와 독립 설치본 검증을 완료했다. 0.3.0 이상 작품은 기존 필드를 유지하며, 0.2.x 이하 작품을 갱신할 때는 [0.3.0 배포 기록](history/2026-11-15-release-0.3.0.md)과 배포용 작품 형식에 따라 제거한 필드를 삭제하고 문안을 새 길이·줄 수 한도에 맞춰 검증한다. 법령·기관 개편과 배경시대에 따른 참고자료 갱신은 해당 작품 제작·배포 시 확인한다. Windows/macOS의 실행 확인과 영상 외부 업로드는 별도 사용·배포 시점에 진행한다. 후속 기능은 실제 작품 제작 피드백을 기준으로 정한다.
