# npm 0.4.0 배포

## 범위

사용자의 버전 상향·npm 게시 요청에 따라 P11 지도·음향·화면 후처리 확장과 P4 창작 참고자료 보완을 `0.4.0`으로 묶었다. 관련 요구는 F1~F6, N1~N4다. km 반경 원·반복 확산 링·흐르는 점선, 음원 반복·재생 속도, 후처리 6종과 공적 대응·화생방·전시 체계·실제 문안 참고자료를 포함한다. `0.3.0`의 작성 필드는 유지한다.

패키지·잠금 파일·CLI 버전과 README 업그레이드 안내를 변경한 소스 기준 커밋은 `625b9b9`다. 기능별 영상·음향 검증은 [엔진 연출 확장](2026-11-15-engine-effects.md), 자료 보완 범위는 [대응 참고자료 보완](2026-11-15-response-references.md)을 따른다.

## 배포 전 검증

- 전체 테스트 75개, 타입 검사와 빌드가 통과했다.
- 최종 tgz는 124개 파일, 8,382,725바이트다. 지도 효과·음원 재생·후처리·웹 미리보기 모듈, 기본 자산과 새 참고자료를 포함하고 소스·테스트·개발 문서·검증 결과는 제외했다.
- 동일 tgz의 `npm publish --dry-run --access public --tag latest`가 통과했고 무결성이 패키징 결과와 일치했다: `sha512-HABiTSx4Zpz/p5KkblwX77A3yXxsSmmltPUGVKyVQeDG1rvRKOps6zatsTKlVTtuUMIFX9AtmdZ2JvDriQC8qA==`.
- 새 `/tmp` 폴더에 tgz를 오프라인 설치했다. `dbs --version`의 `0.4.0`, 작품 초기화, 30초 작품의 경고 없는 검증, 창작 스킬 내보내기와 새 참고자료 7종 포함을 확인했다.
- 설치본의 JSON Schema에서 지도·음원·후처리의 새 필드를 확인했다. 독립 폴더에 기존 기술 검증 입력·음원을 복사해 20초 작품의 경고 없는 검증과 임의 프레임의 원·선·지점·후처리 상태 조회를 통과했다.
- 패키징·예행연습·설치 검증 결과는 `.cache/release-0.4.0/`에 보관하며 배포물에는 포함하지 않는다. Windows/macOS 실행은 확인하지 않았다.
