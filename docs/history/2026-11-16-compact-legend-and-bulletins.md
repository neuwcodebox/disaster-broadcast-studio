# 세로 범례와 관리자 공지

그리드의 수치 분포를 기존 큰 항목 목록보다 좁게 표시할 수 있도록 `legend.layout: colorbar`를 추가했다. 작성 순서대로 색상 구간을 세로로 붙이고 짧은 라벨·선택적 단위를 표시한다. 기본 위치는 지도 오른쪽 위이며 두 범례 방식 모두 네 모서리를 선택할 수 있다. 기존 작품에서 사용하는 항목형 범례의 기본 위치·기호·크기는 유지한다. 관련 요구는 F1, F3, F5, F6, N1, N2이고 PLAN의 P4·P12 보완에 해당한다.

색상 막대는 1~32개 구간, 개행 없는 최대 12자 라벨, 선택적 최대 16자 단위로 지도 높이 안에서 표시한다. 수치·색상은 작품에서 지정하며 수치 정렬·비례 보간·그리드 값 추출은 하지 않는다. 표시를 `src/video/Legend.tsx`로 모으고 기존 콘텐츠 프레임 기준 진입·시간 도약·임의 탐색을 그대로 따른다.

기존 창작 스킬의 상세 연출 문서에는 운영자 공지라는 구분이 있었으나, 본문은 지도·상태·방송 안내를 함께 공개 정보 전달 수단으로 설명했고 형식 표에는 작성 주체가 드러나지 않았다. 가독성 테스트에도 주민 행동요령을 방송 안내로 표시하는 예시가 있었다. 스킬 본문·연출 기준·형식 설명과 예시를 현황판 관리자가 시청자에게 공지하는 서비스 운영 사항으로 통일했다. `bulletin.source`는 관리자·운영팀을 사용하고 지자체·정부·현장기관의 위험·행동 안내는 `alert`로 작성한다. 기관 발표의 보도는 뉴스로 전달한다. 역할 구분은 집필 지침이며 엔진이 기관명 문자열로 판단하지 않는다.

검증은 다음 범위로 완료했다.

- 범례·그리드·기본 계약·가독성 테스트 28개: 기존 목록·기호 유지, 색상 막대 순서·단위·위치, 라벨·항목 수 오류, 시간 도약·컷 이월·임의 탐색을 확인했다. 테스트 사례 수를 직접 확인하기 위해 Node의 `--test-isolation=none`으로 실행했다.
- TypeScript 타입 검사·빌드, CLI JSON Schema 출력과 그리드/범례 작품 검증을 통과했다.
- Chromium/swangle로 실제 1920×1080 PNG를 출력해 세로 범례와 그리드·회전/기울기 카메라·보조 지도의 배치를 확인했다. `.cache/legend-validation/`의 입력·PNG·Schema는 배포하지 않는다.
- 스킬 형식 검사, Markdown 22개 파일의 로컬 링크/앵커 157개와 제목 계층, CLI로 내보낸 스킬 22개 파일의 원본 일치를 확인했다.

버전 변경과 npm 게시, 설치된 사용자 스킬의 갱신은 수행하지 않았다. 기존 설치본에는 다음 배포·스킬 갱신이 필요하다.
