# 문자 이력 표시

수신 데이터는 최신순이었으나 화면은 최신 문자 한 건과 12초마다 바뀌는 과거 한 건만 표시했다. 이 순환 표시를 제거하고 전체 이력을 수신 최신순으로 배치했다. 새 문자는 상단에 추가되고 기존 항목은 아래로 이동한다. 패널 높이를 넘긴 과거 항목은 아래쪽에 누적된다.

표시 컴포넌트의 실제 문안 순서를 검사해 새 수신, 같은 시각의 여러 발송, 시각 도약, 발표 시각이 수신보다 오래된 경우와 역방향 탐색을 확인했다. 같은 수신 시각에는 시나리오 배열의 뒤 항목을 위에 두며, 새 수신이 없는 동안 순서를 유지한다. 장문 본문의 페이지 전환은 유지한다.

독립 작품의 4,859프레임과 4,860프레임을 실제 출력해 기존 세 문자 위에 새 문자가 추가되는 모습을 확인했다. [수신 직전](../screenshots/history-before-receipt.png)과 [수신 직후](../screenshots/history-after-receipt.png)는 같은 1080p60 렌더의 연속 프레임이다. 화면 예시의 지도·글꼴 출처는 [자산 사용권](../../assets/README.md)에 따른다.
