# 정보 변경 피드백

뉴스 교체·문자 수신·상태 변경을 관객이 인지할 수 있도록 기본 전환을 보강했다. 관련 요구는 F3·F4·N1·N2, 구현 단계는 P2·P3이다. 뉴스는 출처·시각·헤드라인을 함께 위로 교체하고 종료 시 퇴장한다. 문자 카드는 내용 높이를 펼쳐 이전 이력을 연속적으로 밀어내며, 이전 최신 카드의 글자 크기·여백도 함께 줄인다. 동시 수신 순서와 이전 이력 보존은 유지한다.

상태는 문구·색상이 유지되는 항목을 다시 강조하지 않는다. 변경 항목은 같은 칸에서 위로 교체하고 짧은 배경·하단 선 강조를 더한다. 해제는 퇴장으로 표시한다. 장문 페이지·방송 안내 전환과 범례·보조 지도 진입에도 짧은 피드백을 적용했다. 기본 이동은 0.45초이며 배경 강조는 약 1.1초 안에 정착한다. 종료 전환은 이벤트 종료 후 최대 0.45초 동안 이전 내용을 남긴다.

모든 효과는 콘텐츠 프레임에서 계산한다. CSS 재생 애니메이션·타이머·이전 DOM 측정에 의존하지 않으며 시계 전환 중에는 기존 내용과 효과를 함께 유지한다. 임의 탐색·구간 렌더·병렬 렌더에서도 같은 결과를 만든다. 시나리오 스키마나 의존 패키지는 추가하지 않았다.

검증은 전체 계약 테스트(각 파일 직접 실행으로 40개 테스트 통과 확인)·TypeScript 빌드, 뉴스 교체/종료·상태 유지/교체/해제·페이지 순환·시계 전환/임의 탐색 회귀 테스트로 수행했다. Chromium에서 프레임별 실제 카드 높이와 상태 위치·불투명도를 측정했다. 유지 상태의 위치·밝기는 일정하고 새 카드 높이는 0에서 내용 높이까지 연속적으로 증가했다. 실제 1920×1080·60fps H.264/AAC 구간을 렌더하고 전환 중 프레임·브라우저 영상 재생을 확인했다. 검증 중 발견한 상태 항목의 순간적인 재배치와 뉴스 문안 중첩은 같은 칸 교체·뉴스 이동량 조정으로 다듬었다.

기술 검증용 시나리오·영상은 임시 경로에서 생성했다. 개발 소스의 변경이며 npm 재게시나 외부 영상 업로드는 수행하지 않았다.
