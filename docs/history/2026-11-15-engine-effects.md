# 지도·음향·화면 연출 확장

엔진 완성도 향상 요청에 따라 하위 에이전트 세 개가 지도, 음원 재생, 화면 후처리를 병렬 구현하고 메인에서 스키마·문서·통합 검증을 진행했다. 기존 타임라인·투영·Remotion Audio를 확장해 새 의존성 없이 작품 데이터에서 연출을 조합할 수 있게 했다. 관련 요구는 F1~F5, N1, N2이며 PLAN의 P11에 대응한다.

지도에는 구면 거리의 km 반경 `circle`, 2.4초 주기 확산 원, `marker.effect: pulse`, `line.flowSpeed`와 선·원의 페이드를 추가했다. 원은 96분할 지리 다각형이며 메인·보조 지도에 같은 좌표를 투영한다. 반복 확산은 기본 지도 캡처를 다시 만들지 않고 SVG 좌표만 갱신한다. 지도 지원 위도 ±85도를 벗어나는 반경은 검증 오류로 반환한다. 점선 흐름은 초당 패턴 주기이며 양수는 작성 좌표 방향, 음수는 반대 방향이다.

음원에는 `loop`와 `playbackRate`(0.25~4)를 추가했다. offset은 원본 초, 반복은 offset 이후부터 원본 끝까지, 이벤트 길이·페이드·침묵은 영상 시간 기준이다. 전체 영상 프레임으로 계산한 숫자 볼륨을 유지해 반복마다 페이드가 다시 시작되는 문제를 피한다. 침묵은 재생 위치를 멈추지 않는다.

후처리에는 `blur`, `desaturate`, `vignette`, `flicker`, `jitter`, `vhs`를 추가했다. 기존 네 종류와 같은 강도 합산·클램프·페이드를 사용하고 프레임·시드에서 CSS/SVG 필터·변형·오버레이를 계산한다. 시간 도약 중 후처리와 shutdown도 유지된 콘텐츠 프레임으로 평가하도록 통일했다. 검정 루트 위의 콘텐츠·후처리보다 blackout/flash를 나중에 합성하고 shutdown의 검정 유지 단계에는 새 후처리를 끈다. 기존 interference/blackout/flash 사이의 이벤트 순서 합성은 유지한다. 기존 shutdown은 강도 0에서 끄고 양수에서 고정 수축을 실행하며 일반 페이드는 적용하지 않는다는 예외를 사용 계약에 명시했다.

검증은 다음과 같다.

- 전체 회귀 테스트 75개와 TypeScript 빌드를 통과했다. 새 계약의 기본값·수치 범위·초과 페이드·컷 이월·투영 한계, 구면 거리·날짜변경선, 확산 주기·점선 방향·지도 마스크 분리, 음원 속도와 독립적인 offset·페이드·침묵, 10종 후처리의 강도·결정성·시간 도약 정지를 확인했다.
- 실제 Chromium/swangle 출력에서 메인·보조 지도의 반경 원·확산·경로와 후처리 합성을 확인했다. 후처리가 활성화된 blackout 및 shutdown 검정 유지 프레임은 1920×1080 전체 RGB 값이 0이었다.
- 360~719 프레임의 6초 H.264/AAC 1920×1080 60fps MP4를 출력했다. 3초 원본(220/440/880Hz)에 offset 1초·2배속·반복을 적용해 440/880Hz가 각각 영상 0.5초 간격으로 반복됨을 PCM에서 확인했다. 침묵 구간은 RMS 0이며 종료 후 진행 중인 880Hz 구간으로 복귀했다.
- 반복 경계가 아닌 405~434 프레임에서 시작한 별도 부분 MP4도 출력했다. 첫 구간은 전체 타임라인의 해당 위치인 880Hz이고 이어지는 침묵은 RMS 0으로, 부분 출력에서 음원이 처음으로 돌아가지 않음을 확인했다.

검증용 입력·음원·출력·분석 결과는 `.cache/engine-validation/`에 두고 배포물에 포함하지 않는다. 실제 작품을 저장소에 추가하지 않았으며 공개 npm 게시·버전 변경은 진행하지 않았다. Windows/macOS 실행과 독립 설치본 검증은 다음 배포 경계에서 수행한다.
