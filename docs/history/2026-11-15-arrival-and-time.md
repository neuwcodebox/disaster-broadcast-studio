# 수신·시간·결말 연출

문자 수신 시 지정된 실제 경계를 짧게 점멸하고 공통 합성 수신음을 한 번 재생한다. 각 기능은 문자 데이터에서 변경·비활성화할 수 있으며 지속 지도 의미는 작품이 정한다. 공통 수신음은 패키지 자산으로 배포하고 작품별 반복 생성과 중복 오디오 이벤트를 제거했다.

컷의 clockTransition은 이전 화면을 유지하면서 표시 시각만 빠르게 이동한다. 일반 사건 시각과 컷 내부의 실시간 계산은 보존한다. 상태 박스는 짧은 진입 변화로 갱신을 알리며 shutdown은 화면 수축과 검은 유지 구간을 제공한다. 모두 임의 프레임 탐색에서도 같은 결과를 만든다.

독립 작품의 모든 문자 대상 코드를 내장 SGIS 행정 데이터와 대조했다. 도청이 특정 시군을 대상으로 보낸 문자는 본문에 대상을 명시하고, 강원 전역 안내는 실제 18개 시군으로 확장했다. 발송 이력 채우기와 위기경보 경계는 구분한다. 전체화면 행동요령은 문자로 옮기고 컷 전환 후 새 정보가 도착하도록 시간과 읽기 간격을 조정했다. 마지막 매체 오염은 문자·뉴스·상태를 유지한 채 송출 신호가 수축하며 끝난다.

계약 테스트는 수신 대상·비활성화·커스텀 음원·컷 전환의 이전 콘텐츠 유지·시계의 실시간 복귀·상태 진입·종료 유지·기존 이력/초기화를 확인한다. 실제 수신·도 전역·시간 이동·종료 프레임과 전체 1080p60 영상을 확인하고 원본 및 20 MiB 미만 전달본을 제공한다.
