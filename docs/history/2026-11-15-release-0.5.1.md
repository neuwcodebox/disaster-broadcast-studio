# npm 0.5.1 배포

## 범위

0.5.0 이후의 역할별 반복 롤플레잉 집필 지침과 창작 스킬 문서 구성을 패치 버전 `0.5.1`로 배포했다. 관련 요구는 F6·N4, 단계는 P4다. 역할별 정보·기억 관리와 `src/writing/` 기록 보존, 스킬 본문·색인·주제별 참고자료의 구성 정리를 포함한다. 엔진 동작과 작품 형식은 변경하지 않았다.

## 게시 결과

패키지·잠금 파일·CLI 표시 버전을 함께 올렸다. 준비 중 실행한 전체 테스트 83개·타입 검사·빌드가 통과했으며, 사용자의 즉시 배포 지시에 따라 추가 검증이나 독립 설치 검증은 진행하지 않았다.

npm 계정 `neuwnpmbox`로 `npm publish --access public --tag latest`를 실행했다. 서버 환경의 자동 브라우저 실행 오류 후 `BROWSER=true`로 재실행했고, 사용자의 브라우저 본인 인증 후 CLI가 `+ disaster-broadcast-studio@0.5.1`과 성공 종료 코드를 반환했다. 배포물은 132개 파일이며 SHA-1은 `84d4370dbcaa71885c671ce44a9f47b95c6217b3`이다.

공개 주소: https://www.npmjs.com/package/disaster-broadcast-studio/v/0.5.1
