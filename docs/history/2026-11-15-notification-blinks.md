# 상태·수신 지역 점멸과 문자 등급 색상

정보 갱신 피드백을 더 알아보기 쉽게 상태와 수신 지역에 3회 점멸을 적용했다. 관련 요구는 F3·F4·N1·N2, 구현 단계는 P2·P3이다. 상태는 0.45초 진입이 끝난 뒤 1.8초 동안 밝기가 3회 내려갔다 돌아오며 배경·하단 선도 함께 강조한다. 문구·색상이 유지되는 항목은 점멸하지 않는다. 수신 지역은 기본 2.4초 동안 채우기가 3회 나타났다 사라진다. 지정 색상·길이·끄기 계약을 유지하며 테두리와 기본 지도 캡처는 변경하지 않는다.

상태와 수신 지역은 같은 프레임 기반 파형을 사용한다. 시간·임의 탐색·구간 렌더의 기존 계약을 유지한다. 일반 `region.pulse`는 지속 강조용의 기존 완만한 효과를 유지하며, 수신 강조만 3회 점멸을 적용한다. 문자 이력은 최신 여부와 관계없이 등급 배지·왼쪽 테두리의 고유 색상을 유지한다. 최신 정보의 글자 크기·배경 위계와 수신 순서는 그대로다.

상태의 점멸 3회·유지 항목의 불투명도, 지도 채우기의 세 번 최대/최소와 사용자 지정 길이·색상, 과거 긴급재난·위급재난·안전안내 카드의 등급 색상을 회귀 테스트로 확인했다. 관련 테스트 파일의 개별 실행과 TypeScript 검사·빌드를 수행하고, 상태 변경·문자 수신·지역 점멸을 포함한 1080p60 H.264/AAC 구간의 실제 프레임을 확인했다. 검증용 입력·영상은 임시 경로에서 생성했으며 npm 재게시는 수행하지 않았다.
