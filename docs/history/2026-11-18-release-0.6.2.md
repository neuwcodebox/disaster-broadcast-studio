# npm 0.6.2 배포

기본 경보·상태·뉴스·방송 안내 효과음이 반복 사이와 재생 끝에서 부드럽게 무음으로 이어지도록 감쇠 곡선을 수정하고 WAV를 다시 생성했다. PLAN의 P3과 요구사항 F4, N1에 해당한다. 신호별 합성 조건은 [기본 효과음 안내](../../assets/audio/README.md)에 기록했다.

패키지·잠금 파일·CLI 표시 버전을 `0.6.2`로 맞췄다. 무음 구간과 경계의 PCM 값 확인을 포함한 전체 테스트 90개, 타입 검사, 배포용 빌드를 통과했다. 최종 tgz는 134개 파일, 8,406,673바이트이며 SHA-1은 `96d836a66a3bbeaf018fe00106b35a7b846cbe9b`다.

npm 본인 인증을 거쳐 이 tgz를 `npm publish --access public --tag latest`로 게시했다. 공개 레지스트리에서 `latest`가 `0.6.2`를 가리키며 SHA-1과 SHA-512 무결성이 최종 tgz와 일치하는 것을 확인했다. [npm 패키지 0.6.2](https://www.npmjs.com/package/disaster-broadcast-studio/v/0.6.2)
