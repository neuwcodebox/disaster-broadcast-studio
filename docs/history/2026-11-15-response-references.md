# 공적 대응·전시·실제 문안 참고자료 보완

F6·N4와 PLAN의 P4에 따라 창작 AI가 ‘정부의 대응’을 구체적인 기관의 판단·조치·발표로 설계할 수 있도록 참고자료를 조사·보완했다. 기존 경보·발송 기준·표준문안 정본은 유지하고 대응 절차와 실제 문안의 근거를 연결했다. 하위 에이전트는 재난 조직, 현장·기반시설, 보건·유해물질, 전시·화생방, 언론 사례를 분담했고 별도 에이전트가 실제 집필로 사용성을 검증했다.

## 조사와 확인 범위

법령의 고정 판본·시행일, 기관 지침의 작성·게시일, 실제 사례의 발생·발표 시점을 나누어 기록했다. 법적 권한·기관 운영 설명·사례에서 실제 이행한 일·창작 적용도 구별했다. 국가법령정보센터의 검색 스니펫과 본문이 섞여 보이는 경우 고정 판본의 실제 본문을 우선했고, 시행령은 필요한 부칙까지 확인했다. 2027년 시행 예정 내용을 2026년 적용 기준에 섞지 않았다. 모든 현행 개정·지역별 계획을 포괄 검증했다는 뜻은 아니다.

질병관리청 원인불명 질병 집단감염 대응지침 제3판, 화학물질안전원 역할 설명, 기본법·통합방위법·병역법·계엄법과 분야별 법령, 행안부·국무조정실·지자체·시설 운영자의 공개 대응 자료를 활용했다. 행안부 2025년 비상시 국민행동요령은 텍스트 추출이 깨져 인쇄 13~19쪽의 실제 화면을 확인했다. 비공개 작전·계획 내용이나 확인되지 않은 고정 대응시간·반경·동원 비율은 넣지 않았다.

문자 20건은 공식 목록과 개별 상세페이지에서 문안·등록일을 정확히 대조했다. 등록일을 실제 송출·휴대전화 수신 시각으로 바꾸지 않는다. 문자 데이터셋의 공공누리 제4유형을 확인해 대량 재사용 권한을 가정하지 않고 짧은 인용·분석으로 수록했다. 기사 제목은 기사별 한 제목만 인용했으며 본문·사진·영상은 포함하지 않았다. 직접 본문 열람을 확보하지 못한 16건은 개별 원기사 검색 색인의 제목·입력일로 대조한 범위를 †로 표시했다. 나머지 11건과 확인 수준을 구별한다.

## 검증과 적용 한계

- 스킬 형식 검사를 통과했다. Markdown 18개 파일의 로컬 링크·앵커 112개를 확인했고 누락이 없었다.
- 실제 `dbs skill --out`으로 스킬·참고자료·예제 20개 파일을 내보내 원본 파일 집합·내용의 일치를 확인했다.
- 원인불명 집단증상·정전의 초동 40분과 공습경보 뒤 이상증상·부분동원/계엄 언급이라는 두 독립 집필 요청에서 자료 탐색·기관별 대응·문자/뉴스 작성을 검증했다. 평가용 작품은 저장소에 기록하지 않았다.
- 첫 검증에서 나온 원인불명 사건의 문자 선택 경로는 실제 문자 사례집의 적용 절에서 보완했다. 두 번째 검증에서 확인한 국가·부분동원령 자체의 선포권·근거 법률·전체 절차 미확인 경계는 전시 자료에 명시했다. 기관의 개념 안내와 병역법상 소집 집행을 실제 선포문의 근거로 확장하지 않는다.

검토용 다운로드·렌더링·사례 대조 자료는 `.cache/`에 격리했다. 임시 PDF 렌더러도 그 안에만 두고 엔진 의존성은 변경하지 않았다. 문서·스킬 개정이므로 엔진 전체 테스트·빌드·영상 출력은 실행하지 않았다. 설치된 사용자 스킬·GitHub 원격·공개 npm 배포는 갱신하지 않았다.
