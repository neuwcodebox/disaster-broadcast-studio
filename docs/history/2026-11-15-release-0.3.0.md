# npm 0.3.0 배포

## 범위와 계약 변경

사용자의 버전 상향·npm 게시 요청에 따라 선택적 스트리밍 채팅, 모바일 가로 가독성과 짧은 문안의 전문 표시, 시간 도약의 빠른 재생 연출을 `0.3.0`으로 묶었다. 작성 주체·시청자 관점과 실재하는 공식 상태 체계의 창작 지침도 포함한다. 관련 요구는 F1~F7, N1~N3이며 P8~P10의 공개 배포에 해당한다. 패키지·잠금 파일·CLI 버전과 README 업그레이드 안내를 변경한 소스 기준 커밋은 `00074d6`이다.

기존 작품은 제거한 `pageSeconds`·`corrects`를 삭제하고 문안·표시명을 현행 길이·줄 수 한도에 맞춰 간결하게 수정해야 한다. 정확한 한도는 배포용 [작품 형식](../../skills/scenario-writing/references/format.md)을 따른다. 자동 페이지 분할과 정정 배지·연결은 생성하지 않는다.

## 배포 전 검증

- 전체 테스트 61개, 타입 검사와 빌드가 통과했다.
- 최종 tgz는 115개 파일, 8,339,775바이트다. 채팅·시간 도약·웹 미리보기 모듈, 지도·효과음·README 이미지·창작 스킬을 포함하며 소스·테스트·개발 문서는 제외했다.
- 동일 tgz의 `npm publish --dry-run --access public --tag latest`가 통과했고 무결성 값이 일치했다: `sha512-e2zylAzFOsNHiiqVcZ66KTwPXD0PxsZakLytEpD2Afuy3/e470w5HJ69/fusBefWTIGp+FFzBqJbdnhO+agR5w==`.
- 새 `/tmp` 폴더에 tgz를 오프라인 설치했다. `dbs --version`의 `0.3.0`, 작품 초기화, 30초 작품의 경고 없는 검증, 창작 스킬 내보내기를 확인했다.
- 설치본의 JSON Schema를 출력하고 채팅 입력 허용, 제거한 두 필드와 너무 긴 문자의 거부를 확인했다.
- 설치본의 기술 검증 입력으로 채팅·문자·뉴스·지도와 시간 도약 중간의 실제 PNG를 출력하고 확인했다. 시간 도약에서도 기존 화면을 유지하며 중앙 빠른 재생 아이콘·가로 잔상·주사선과 선명한 시계를 표시했다. 기술 검증 입력의 문자 읽기 시간 경고는 유지했다. 구간 영상·모바일 축소 화면의 검증 범위는 각 기능의 기존 이력을 따른다.

## 게시 결과

- 공개 주소: https://www.npmjs.com/package/disaster-broadcast-studio/v/0.3.0
- 완전히 새 `/tmp` 폴더에 공개 레지스트리의 `disaster-broadcast-studio@latest`를 설치했다. 설치 잠금 파일의 버전 `0.3.0`·레지스트리 tgz 주소·무결성이 일치했고, `dbs --version`, `dbs init`, 생성한 30초 작품의 `dbs validate`가 경고 없이 통과했다.
