# 그리드 구조 정리

그리드의 픽셀 계산과 React 표시를 `src/video/map/grid/`의 두 파일로 분리했다. `raster.ts`는 좌표·색상·픽셀 계산만 담당하며 React·DOM·MapLibre에 의존하지 않는다. `index.tsx`는 캔버스와 캐시를 관리하고 지도에서 준비된 투영 함수·뷰포트 정보를 받는다. 지도 컴포넌트가 그리드 DOM을 조회하고 캐시하던 코드를 제거했다. 자산 파일 로딩은 `loadGrids` 함수로 묶고 작업공간 초기화의 생성 파일 목록은 한 번만 선언하도록 정리했다.

작품 형식·폴더 구조·화면 표현은 유지했다. 별도 클래스 계층·서비스 인터페이스·호환 모듈은 추가하지 않았다. 기존 단일 그리드 모듈과 대응하는 이전 빌드 파일은 제거했다. README와 창작 스킬의 사용 계약은 바뀌지 않았다. 관련 요구는 F3, F5, N2이며 PLAN의 P5·P12 유지보수에 해당한다.

그리드·지도 효과·작업공간·미리보기·기본 계약 테스트 33개와 TypeScript 빌드를 통과했다. 실제 Chromium/swangle의 동일 프레임 PNG를 RGBA로 디코딩해 픽셀 일치를 확인했고, 시간 도약과 그리드 교체를 포함한 570~689 프레임 구간도 이전 MP4와 120개 영상 프레임의 해시가 모두 일치했다. 비교 결과는 `.cache/grid-validation/`에 두며 배포하지 않는다.
