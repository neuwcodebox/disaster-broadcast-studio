# 창작 스킬 문서의 구성 정리

## 문서별 역할과 설명 순서

창작 스킬의 본문과 참고자료를 문서의 목적, 설명의 수준, 제목 위계, 앞뒤 문맥을 기준으로 검토했다. 기존 지침을 개별 문장으로 추가하는 대신 집필·제작 흐름과 주제별 설명 안에 통합했다. F6·P4의 제공 범위와 엔진 계약을 유지하며 8개 스킬 문서를 재구성했다.

- `SKILL.md`는 작업 범위·집필 관점·사건 설계와 롤플레잉·연출·작품 검증·전달 순으로 안내한다. 자료 전체 목록은 색인으로 모으고, 구체적인 기능·수치 설명은 관련 참고자료에 둔다.
- `references/README.md`는 집필·제작, 제도·대응, 경보·문안·사례를 구별하는 탐색 안내다. 자료의 판본·확인 수준과 적용 범위는 별도 절에서 설명한다.
- `roleplaying.md`는 역할 준비·반복 진행·기록과 수정·시나리오 정리의 흐름을 따른다. 역할 문맥과 지시 예시는 준비의 하위 항목이며, 기록 보존과 전개 수정은 집필을 이어 가는 공통 절차로 묶는다.
- `direction.md`는 매체별 전달 범위와 정보 시간차를 바탕으로 호흡·변화, 지도·효과, 문안·완성본 검토를 설명한다. 도입·읽기 간격·결말을 호흡의 하위 항목으로 정리하고 매체별 역할을 중복 나열하지 않는다.
- `audio.md`는 소리의 의미와 기본 알림·고유 음향 선택을 먼저 설명하고 WAV 합성·결과 연결로 이어진다. 기본 알림의 상세 수치와 설정은 `format.md`의 계약을 참조한다.
- `format.md`는 작업공간과 CLI, 작품 필드, 내용·지도·음향·화면 이벤트를 구별한다. 상태 예제는 상태 설명에서 오프닝 이후인 5초부터 시작하며, 화면 후처리와 결말 조합은 음향·화면 효과에 둔다. 지도 그리드 절에 있던 음원 합성 링크도 로컬 음원 설명으로 옮겼다.
- `news-writing.md`는 취재와 표현·문안 점검·법정 방송의 역할·실제 발표 사례 순으로 설명한다. 일반 집필 기준을 개별 사례의 하위 항목에서 분리하고, 집계 단위 설명을 사실·확인 범위의 문맥에 통합했다.
- `civil-defense.md`는 규정의 장·조문·호와 별표의 문안 유형·세부 항목에 맞춰 제목 수준을 정리했다. 본문 호목을 조문과 같은 제목으로 표시하던 부분을 일반 본문으로 복원하고, 자료 선택표에서 실제 규정·별표로 이동하게 했다.

대응·위험정보 요약, 발송 기준·표준문안, 실제 문자·헤드라인 사례, 설치 안내도 설명 범위와 구성을 검토했다. 주제와 원문·해설의 구별이 유지되는 부분은 재작성하지 않았다. 집필 원본의 `src/writing/` 보존과 반복 롤플레잉의 정보·기억 관리 원칙은 유지한다. 폴더별 용도는 작품 파일 안내에서 원본과 생성 결과를 함께 설명한다.

## 검증 범위

- 스킬 형식 검사를 통과했다. 스킬·설치 안내와 관련 개발 문서의 Markdown 22개 파일에서 제목 수준과 로컬 링크·앵커 154개를 확인했다.
- 민방위 규정 본문·별표는 제목 표식과 공백을 제외한 텍스트가 변경 전과 일치했다. 뉴스 자료의 실제 발표·보도 사례 6개도 제목 수준 외의 본문을 그대로 보존했다.
- 작품 형식의 YAML·JSON 예제는 위치 이동과 상태 예제의 시작 시점 조정을 제외하고 일치했다. 엔진 필드·기본값은 변경하지 않았다.
- 실제 CLI로 내보낸 스킬·참고자료·예제 22개 파일의 경로 집합과 바이트 내용이 정본과 일치했다. 변경 diff의 공백 오류도 없었다.

문서 구성 개정이므로 엔진 테스트·빌드·영상 출력과 새 롤플레잉 실습은 수행하지 않았다. 공식 제도의 판본과 출처를 새로 조사한 작업이 아니며, 설치본·GitHub 원격·npm 배포물을 갱신하지 않았다.
