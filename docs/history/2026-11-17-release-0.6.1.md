# npm 0.6.1 배포

## 범위

지도 그리드의 색상·투명도 공간 보간과 최신 문자 강조의 부드러운 이관을 `0.6.1`로 묶었다. 관련 요구는 F3, F5, N1, N2이며 PLAN의 P2·P12 보완에 해당한다. 기존 작품 형식은 유지한다. 그리드 구현·실제 화면 검증은 [그리드 보간](2026-11-17-grid-interpolation.md)을 따른다. 문자 강조는 이전 최신 카드의 배경색·본문 색상을 글자 크기와 같은 진행률로 낮추며, 동시 수신 순서와 임의 탐색의 재현성을 유지한다.

## 배포 준비와 검증

패키지·잠금 파일·CLI 표시 버전을 `0.6.1`로 맞췄다. 전체 테스트 89개, 타입 검사와 빌드를 통과했다. 미리보기 HTTP 테스트는 로컬 포트 접근이 필요한 실행 권한으로 확인했다. 공개 레지스트리의 기존 latest는 `0.6.0`이며 `0.6.1`은 미게시 상태였다.

최종 tgz는 134개 파일, 8,390,870바이트다. 빌드·자산·스킬·README·라이선스를 포함하고 소스·테스트·개발 문서·캐시는 제외한다. SHA-1은 `70146bdf3f2a3731e02efbd88646fd273c8f1c2f`이며 무결성은 `sha512-e1v03c/uX4y/VOLXiNHliOKfEjeGNogRcIkrDDo9H3YuksybGVsyl5jQmHxhmWaNWxEucedV+P0YIbHW/Lveog==`다. 동일 tgz의 공개 게시·latest 태그 사전 검사와 무결성 일치를 확인했다.

별도 폴더에 tgz를 설치해 CLI 버전, 기본 작품 초기화·검증, 기존 그리드 작품 검증·540프레임 상태 조회, JSON Schema 출력과 스킬 내보내기를 확인했다. 배포본의 README·그리드 및 문자 빌드·내보낸 스킬이 원본과 일치했다. 검증 자료는 `.cache/release-0.6.1/`에 둔다. 실제 PNG는 그리드 기능 구현 시 확인했으며 배포 과정에서 새 영상 출력은 반복하지 않았다.

## 게시 결과

npm 계정 `neuwnpmbox`의 로그인과 별도 게시 본인 인증을 사용자가 완료한 뒤, 검증한 tgz를 `npm publish --access public --tag latest`로 게시했다. CLI는 `+ disaster-broadcast-studio@0.6.1`과 성공 종료 코드를 반환했으며 레지스트리 처리가 진행 중임을 안내했다. 후속 처리 뒤 공개 레지스트리의 버전 `0.6.1`, `latest: 0.6.1`과 최종 tgz의 SHA-1·SHA-512 무결성 일치를 확인했다.
