# 음원 생성과 지도 중첩

## 구현

- `dbs audio`에서 외부 ES 모듈을 Tone.js 15.1.22의 OfflineContext로 실행한다. 기존 Remotion Chromium과 Artifact를 이용해 PCM16 WAV·생성 기록을 반환한다. 상대 모듈, 로컬 샘플 폴더, 시드 난수, 오류 전달·부분 파일 정리를 지원한다.
- 기존 파일 기반 영상 오디오는 유지한다. 창작 스킬에 실행 가능한 수신음·시드 노이즈 예제와 제작·경로·사용권·검증 안내를 포함했다.
- 행정구역 채우기와 윤곽선의 색·불투명도·폭을 독립 설정한다. 펄스 채우기도 윤곽선 아래에 합성하며 시나리오 지정 문구·기호의 시간 범례를 제공한다. 경보와 지리적 의미를 엔진에서 추론하지 않는다.
- 지역 코드 검색의 내장 데이터 출처·지원 범위와 실제 검색·검증 명령을 스킬에 명시했다.

## 확인

빠른 WAV·지도 중첩·문자 이력 계약과 TypeScript 빌드가 통과했다. 외부 npm 패키지 설치본에서 스킬을 복사하고 로컬 샘플을 읽어 WAV를 출력했다. 같은 시드의 노이즈 WAV는 동일했으며, 합성 오류는 실패로 반환하고 부분 WAV를 남기지 않았다. 실제 펄스·윤곽선 겹침 프레임도 확인했다.

독립 작품은 개발 저장소 밖에서 YAML 작성 원본과 Tone.js 모듈·음원을 보관한다. 문자 발송 이력은 채우기, 작중 경보 발령 지역은 윤곽선·범례로 구분하고 발령 보도·문안과 시점을 맞췄다. 최신 문자가 위에 쌓이며 마지막 질문이 뉴스·문자·상태·안내 화면으로 번진다.

전체 1920×1080 60fps 영상과 수정한 마지막 구간을 출력해 무손실 영상 연결 후 연속된 전체 음향을 유지했다. 완성본은 18600 영상 프레임과 48kHz AAC 트랙을 가진다. 지도 중첩·마지막 문구·연결 경계의 실제 영상 프레임을 확인했다. 음향의 통합 음량은 약 -25.5 LUFS, true peak는 -7.6 dBFS다. 음성·TTS·외부 음악은 사용하지 않았다.

Linux x64, Node.js 24.22.1, Chrome Headless Shell 158과 소프트웨어 WebGL에서 확인했다. 이 환경의 제한된 네트워크 인터페이스 조회는 저장소 밖의 실행 전용 보정으로 처리했다. Windows/macOS는 직접 실행하지 않았다. 공개 npm 게시·유튜브 업로드는 수행하지 않았다.
