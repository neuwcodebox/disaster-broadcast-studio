# npm 0.5.0 배포

## 범위

P12 범용 지도 그리드와 P5 작품 작업공간 구조 개선을 `0.5.0`으로 묶었다. 관련 요구는 F1, F3, F5, F6, N1~N4다. 셀별 색상·투명도, 시점별 교체·중첩·페이드, 메인·보조 지도 투영, 미리보기의 파일 수정 감지와 실행 가능한 합성 그리드 생성 예제를 포함한다. 작품 초기화는 원본·생성 코드를 `src/audio/`·`src/maps/`, 생성 결과를 `output/audio/`·`output/maps/`에 모으며 `.gitignore`를 생성하거나 수정하지 않는다.

## 배포 준비

- 패키지·잠금 파일과 CLI 표시 버전을 `0.5.0`으로 맞췄다.
- 전체 테스트 83개, 타입 검사와 빌드가 통과했다.
- 이전 빌드 폴더를 제거하고 최종 tgz를 생성했다. 131개 파일, 8,386,103바이트이며 소스·테스트·개발 문서·검증 결과와 이전 그리드 모듈 빌드 파일은 포함하지 않았다.
- `npm publish --dry-run --access public --tag latest`가 통과했다. 최종 무결성은 `sha512-RFOUQCHje6Dw8rpt8xVtssPNmICbnuXI6CJQL5GAC7sAxVTDwEfB6/bfcWQpgvZph8RujLSHnF4rlXGofWwFOg==`다.
- 새 `/tmp` 폴더의 tgz 설치본에서 CLI 버전·30초 기본 작품 검증·새 폴더 구조·기존 산출물 보존·경로 충돌 보호·README 일치·스킬 내보내기와 그리드 생성 예제를 확인했다. 생성 그리드를 참조한 작품 검증·시점별 교체·출처 출력과 실제 1920×1080 PNG 출력도 완료됐다. 결과는 `.cache/release-0.5.0/`에 둔다.

## 게시 결과

npm 계정 `neuwnpmbox`와 기존 `latest: 0.4.1`을 확인한 뒤 최종 tgz의 공개 게시를 실행했다. 사용자의 브라우저 본인 인증 후 CLI가 `+ disaster-broadcast-studio@0.5.0`과 성공 종료 코드를 반환했다. npm은 레지스트리 반영까지 수분이 걸릴 수 있음을 안내했다.
