# 작성 주체와 시청자 관점의 집필 지침

## 판단과 반영

기관·출처·시각이 맞더라도 문장의 전달 목적과 정보 접근 범위가 어긋나면 현실감이 깨진다. F6의 창작 지침과 P4의 독립 스킬에 작성 주체의 환경·정보·권한·입장·목적·수신자, 정보와 소리가 방송에 들어오는 경로를 판단 기준으로 반영했다.

- 재난문자는 발송기관이 상황을 파악하고 주민에게 위험·조치를 알리는 공적 안내로 쓴다. 기관의 책임과 발송 목적에 따라 대상자에게 필요한 내용을 선별한다.
- 뉴스는 기자의 취재 환경과 확인 범위에 맞춰 속보·후속 보도·현장 연결을 구별하고 절제한다. 개인의 즉각적인 반응·목격담·일상 중계는 주로 채팅에 둔다.
- 현황판은 공개된 문자·뉴스를 모아 스트리밍하는 서비스다. 지도·상태·방송 안내에 비공개 정보 접근이나 재난 대응 지휘 권한을 암묵적으로 부여하지 않는다.
- 상태바는 실재하는 공식 체계의 단계·발령 상태만 표시한다. 체계의 근거와 작품 안의 공개 여부를 확인하며 개별 조치·상황 요약은 뉴스 등 적절한 매체로 전달한다. `status-systems.md`와 파일 형식 안내에도 같은 기준을 반영했다.
- 음향은 서비스 알림·방송에 포함된 소리·배경음의 역할을 구별하고 전달 경로와 화면 맥락을 맞춘다. 시청 환경에서 받아들일 출처와 의미까지 검토하며 기본음에도 같은 기준을 적용한다.

핵심 전제는 `SKILL.md`, 상세 판단과 매체별 기준은 `direction.md`, 보도 형태는 `news-writing.md`, 소리의 의미는 `audio.md`에 두었다. 공식 규정·표준문안 원문과 엔진 동작은 변경하지 않았다.

## 검증 범위

스킬 형식 검사를 통과했고, 상태바 기준을 반영한 Markdown 9개 파일의 로컬 참조·앵커 50개와 변경 diff·공백 오류를 확인했다. 문서 개정이므로 엔진 전체 테스트·빌드·영상 출력은 검증 범위에 포함하지 않았다. 실제 새 작품에 적용한 결과와 설치된 스킬·공개 배포물의 갱신은 별도다.
