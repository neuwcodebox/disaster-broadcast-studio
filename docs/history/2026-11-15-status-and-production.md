# 방송 화면·창작 지원·독립 작품 출력

## 화면과 계약

정상 화면의 제목, 문자 이력 제목·개수, 본문과 중복된 발신자 칸, 제목·뉴스 출처 옆 장식선을 제거했다. 기본 지도에는 지역명·시설명·출처를 상시 표시하지 않는다. 사용자가 지적한 ‘백령면사무소’는 지도 제공자의 POI가 아니라 지리 검증용 외부 입력에 넣었던 명시적 marker 캡션이었다. 그 입력과 기본 미리보기의 지점·캡션을 제거했으며 선택적 작품 캡션 기능은 유지했다.

상태 표시줄은 문구·색상 목록과 기간만 받는다. 특정 경보 체계나 단계를 엔진에서 결정하지 않는다. 방송 안내 화면, 지리 좌표 기반 영역·진행선을 추가하고 `inspect`, 지역 검색, 게시용 `credits` 명령을 제공했다. 정확한 계약은 배포용 [형식 설명](../../skills/scenario-writing/references/format.md)에 있다.

## 지도 성능과 출처

정밀 경계를 단순화하는 대신 정지 지도는 동일 해상도의 2D 캔버스로 복사해 재사용한다. 펄스도 같은 지도의 투명 캡처를 프레임별 불투명도로 합성한다. 카메라 이동 때는 MapLibre를 갱신하며 완료 후 다시 캐시한다. 이 환경에서는 WebGL 캔버스의 동기 PNG 직렬화가 지연되어, PNG 변환·복호화 없이 캔버스를 복사하는 방식을 사용했다. 정밀 지도 준비에는 Remotion의 기본 30초보다 긴 준비 시간을 허용한다.

동봉 지도 이용조건에서 영상 위 고정 워터마크 의무는 확인되지 않았다. 출력별 게시용 출처 파일에 제공자·원자료·라이선스·가공 내용과 SGIS 권장 출처 문구를 보존한다. 기계 메타데이터만으로 대신하지 않고 게시 설명에 포함한다. 폰트·자산 재배포의 라이선스 파일은 그대로 동봉한다. 세부 근거는 [자산 사용권](../../assets/README.md)에 둔다.

## 창작 지원

소방동원령·경찰 비상근무·재난별 위기경보·군사 대비태세를 [상황 지표 자료](../../skills/scenario-writing/references/status-systems.md)에 구별해 정리했다. 법령 판본과 과거 공개 설명·실시간 발령값을 구분한다. 사건·확인·발령·보도 시점, 매체별 역할과 읽을 호흡은 별도의 창작 연출 자료에서 다룬다. 실제 작품은 엔진 저장소에 포함하지 않는다.

## 확인한 결과

빠른 외부 계약 검사·타입 검사를 통과했다. 실제 영상에서 상태 박스·방송 안내·영역·진행선·펄스·카메라 이동 종료·컷 전환·보조 지도를 확인했다. 전체 지도와 백령도 프레임에서 실제 경계와 라벨 제거를 직접 확인했다. 화면 예시의 출처·사용권은 위 자산 문서와 같다.

외부 작업 공간에서 설치한 패키지로 독립 단편 「수신 대기」를 출력했다. 영상은 310초, 1920×1080, 60fps H.264이며 48kHz AAC 음향을 포함한다. 오프닝의 허구 고지, 세 실시간 구간과 시각 도약, 주요 문안·지도·방송 전환·마지막 화면을 실제 출력에서 확인했다. 직접 합성한 음원을 사용했으며 실측 후 음량을 보정했다. 영상 스트림은 재인코딩하지 않고 음향을 마스터링했고, 재현용 음원과 생성 스크립트에도 같은 게인을 반영했다. 완성 음량은 약 -24.4 LUFS, true peak -5.9dBFS다.

작품 입력·음원·생성 스크립트·게시 설명은 엔진과 별도로 전달한다. npm 공개 게시나 영상 외부 업로드는 수행하지 않았다. Linux 소프트웨어 WebGL 환경에서 확인했으며 다른 OS·GPU의 실제 실행을 확인한 것으로 확대하지 않는다.
