# 작품 초기화·스킬 배포·문안과 후처리

`dbs init [directory]`는 작품 YAML·README·음향 폴더·합성 코드 시작점을 만든다. 스킬은 GitHub의 독립 Agent Skills 폴더를 Vercel skills로 사용자 범위에 설치·갱신한다. npm 동봉본의 `skill --out`은 오프라인 내보내기 용도로 유지한다.

외부 npm 설치본에서 빈 작품 폴더를 초기화하고 생성 YAML의 유효성·시나리오/음원 코드 경로·기존 파일 충돌 시 보존을 확인했다. Vercel skills의 실제 프로그램을 임시 홈과 XDG 상태 폴더, 격리 Git 전송으로 실행해 GitHub 형태의 경로 설치와 지정 스킬 갱신·Claude 링크를 확인했다. 개인 GitHub 인증을 가져오거나 실제 사용자 스킬을 변경하지 않았다. 비공개 저장소의 실제 사용에는 사용자의 Git·GitHub CLI·SSH 접근 권한이 필요하다. 초기 검증의 XDG 추적 기록은 제거하고 이후 검증은 홈·상태 폴더 모두 격리했다.

공식 발송 목록의 산불 발생·진화, 화재 연기, 안개, 정전, 정상 운행, 도로 통제와 정전·화학물질·오인 신고 기사에서 날짜·출처·문장 구조를 정리해 기존 참고자료에 보강했다. 재난문자 표준문안의 PDF 열 맞춤 줄바꿈을 문장으로 연결하고 163항목·90/157자 구분 및 공백 제외 글자·문장부호를 보존했다. 이 추출 형식 문제를 예시 영상의 문체 문제 원인으로 단정하지 않았다.

독립 작품의 문자·헤드라인을 매체별 역할과 자연스러운 한국어로 검토했다. 단독 수신해도 행동이 읽히게 하고, 신고·확인·원인 조사를 구분했다. 마지막 매체 오염 연출과 발송·발령 지역 구분은 유지했다. 허구 고지는 첫 5초에 큰 글자로 표시한다.

선택적 잡음·주사선·색 채널 분리·수평 신호 누락을 프레임 기준 후처리로 제공한다. 기존 세 효과는 유지하며 기본 화면에 강제하지 않는다. 계약 테스트와 실제 중첩 프레임을 확인하고 작품의 마지막에 약한 주사선·짧은 색 분리만 적용했다. 전체 재출력과 마지막 구간 출력을 무손실 연결해 연속된 원래 오디오를 유지했다. 완성 영상은 1920×1080, 60fps, 18600프레임과 AAC 48kHz이며 시작·문안·범례·마지막 연출을 실제 프레임에서 확인했다.
