# 1차 개발 마무리: 책임 분리와 사용 문서

## 범위와 판단

P1~P6 구현 이후 유지보수를 위한 정리다. 기존 함수·React 컴포넌트 경계를 활용해 중복과 혼합된 책임을 줄였다. 별도 서비스 계층·클래스 계층·가상 호환 어댑터는 추가하지 않았다. 작품 형식과 기존 CLI 명령은 유지했다. 관련 요구는 F1~F6, N1~N4이며 기능 단계는 추가하지 않는다.

## 구현

- `src/output.ts`의 `withOutputFiles`가 영상·프레임·음원의 임시 디렉터리, 결과·부속 파일 확인, 기존 파일 보호와 정리를 맡는다. 모든 필수 파일을 준비한 뒤 본 결과를 마지막으로 게시한다. 렌더 중 생긴 충돌도 배타적 하드 링크로 보호하며, 기본 모드의 게시 실패 시 이번 호출이 게시한 파일을 정리한다. `--overwrite`는 파일별 rename이며 파일 집합 전체의 트랜잭션은 아니다.
- `Broadcast`의 글꼴 로딩은 `useBundledFonts`, 음향은 `AudioTrack`, 방송 안내는 `Bulletin`으로 분리했다. 음소거 여부는 프레임당 한 번 계산한다. 안내 페이지는 다른 화면 정보와 같은 `contentFrame`을 사용해 시계 전환 중 이전 내용을 유지한다.
- 기관·음원 참조는 직접 선언한 사전 키만 인정한다. `constructor`·`toString` 같은 기본 객체 속성이 존재하지 않는 참조를 통과시키던 경로를 막고, 같은 이름을 실제로 선언한 사용은 허용한다.
- 지역 강조에도 음원·화면 효과와 같은 페이드 길이 검증을 적용했다. 문자 읽기 경고는 기존 3초 대신 실제 5초 오프닝을 제외한다.
- 사용하지 않는 지도 `moving` 속성과 `load.ts`의 패키지 경로 재노출을 제거했다. CLI와 지도 시간 변환은 공통 FPS 상수를 사용한다. 타임라인 코드를 읽기 쉬운 형식으로 정리하고 수신 강조의 반환 타입을 실제 지역 이벤트로 좁혔다.

## 문서와 배포물

README를 소개·설치·첫 출력·결과 파일·작성 도구·개발 순서로 다시 작성했다. 정확한 작품 필드는 배포용 형식 문서에 유지하고 README에서는 연결한다. 자산 설명의 ‘기본 음원 없음’을 현재 제공하는 CC0 수신음에 맞췄으며, 형식 문서에 부속 파일 충돌 보호를 명시했다. npm 메타데이터에는 저장소·홈페이지·이슈 주소를 추가했다.

## 검증

Linux x64, Node.js 24.22.1, Chrome Headless Shell 158.0.8127.2, WebGL `swangle`에서 확인했다.

- `npm test`: 전체 8개 테스트 파일 통과. `node --import tsx --test --test-isolation=none tests/*.test.ts`로 개별 계약·회귀 테스트 36개 통과도 확인했다.
- `npm run typecheck`, `npm run build`, `git diff --check` 통과.
- 출력·부속 파일 충돌, 실패 시 기존 파일 보존·임시 파일 정리, 부속 파일 누락, 렌더 중 생긴 충돌, 명시적 덮어쓰기를 결정적 테스트로 확인했다. 참조·지역 페이드·오프닝 읽기 시간 회귀 테스트를 추가했다.
- 실제 Tone.js 모듈에서 0.7초·48kHz·스테레오 PCM16 WAV와 합성 기록을 생성했다. 피크 약 0.14, 클리핑 0개를 확인했다.
- 실제 지도·보조 지도·문자 정정·뉴스가 있는 1920×1080 PNG를 출력하고 한글과 레이아웃을 확인했다.
- 300~329 프레임 구간을 MP4로 출력해 ffprobe로 H.264/yuv420p·1920×1080·60fps, AAC·48kHz·스테레오를 확인했다. 테스트 입력의 해당 구간에는 silence 이벤트가 있다.
- `npm pack` 결과에 빌드 모듈·자산·스킬이 포함되고 소스·테스트·검증 결과가 섞이지 않는지 확인했다. 외부 빈 폴더에 tgz를 설치해 실제 `dbs` 실행명으로 init·validate·inspect를 실행했다. 초기화한 30초 작품은 경고 없이 검증됐다. 외부 설치본으로 방송 안내·상태·뉴스가 있는 PNG 출력도 확인했다.
- 출력 메타데이터의 프레임 범위·최종 출처 파일명과 임시 경로가 남지 않는 것을 확인했다. 검증 입력과 미디어는 저장소 밖 임시 폴더에 뒀다.

기존 전체 작품 출력을 반복하지 않고 변경 경계의 프레임·짧은 구간·외부 설치를 검증했다. Windows/macOS 실행 확인과 공개 배포는 PLAN의 별도 범위로 유지한다.
