# 기본 효과음과 등급별 경보

관련 요구·단계: F4, F5, N2 / P3.

문자 한 종류뿐이던 기본음을 정보 갱신의 종류와 문자 등급에 맞게 확장했다. 안전안내의 기존 WAV·0.55초·재생 볼륨 0.65는 유지한다. 긴급재난은 2.4초의 경보 3회, 위급재난은 4.2초의 빠른 경보 3회와 지속음이다. EAS풍의 두 주파수 불협화음에 약한 배음을 더했으며 재생 RMS는 안전안내 약 0.154, 긴급 약 0.224, 위급 약 0.329다. 상태 0.38초, 뉴스 0.7초, 방송 안내 1초는 각각 다른 상승음·화음이다. WAV 자체의 클리핑은 모두 0이다.

기본음 목록이 파일·길이·볼륨을 함께 관리한다. 스키마의 `sound` 설정을 alert/status/news/bulletin이 공유하고 기본·비활성화·사용자 음원을 지원한다. 로더는 사용되는 기본 파일만 연결하며 출처에도 반영한다. 상태는 실제 항목 변경·등장·해제에 한 번만 울린다. 동일 항목을 연속 유지하면 무음, 인접 교체는 새 상태의 설정, 자연 종료는 이전 상태의 설정을 따른다. 뉴스·방송 안내는 시작에만 울린다. 음원 재생은 영상 끝으로 제한하며 silence와 중간 구간 출력은 기존 AudioTrack 경로를 사용한다.

검증:

- TypeScript 빌드·타입 검사 통과.
- 관련 테스트 33개 통과: 등급 선택·길이·볼륨, 상태 유지/교체/해제, 기본/끄기/교체, 자산 참조 오류, 영상 끝 절단, WAV PCM·클리핑·등급별 RMS, 로더·출처와 기존 타임라인/정보 전환 계약.
- 실제 AudioTrack을 14초 H.264/AAC 기술 검증 영상으로 출력하고 8.5초부터 2초 구간도 출력했다. PCM 검사로 6종의 재생, 9~9.5초 silence, 구간 출력의 음량·시간 일치를 확인했다. 화면 변경은 없어 지도·방송 전체 화면 재출력은 하지 않았다.
- 채팅 scratch에 실제 재생 볼륨을 적용한 6개 MP3, 순서대로 듣는 WAV, 인라인 HTML 플레이어를 생성했다. 합성 소스와 PCM WAV·메타데이터는 패키지 자산에 포함한다.

재생성은 `npm run build` 후 `node scripts/build-audio-assets.mjs`로 수행한다. 이번 변경은 로컬 소스·자산에 반영했고 npm 재게시는 수행하지 않았다.
