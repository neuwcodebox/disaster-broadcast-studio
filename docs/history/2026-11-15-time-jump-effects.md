# 시간 도약 전환

상단 시계 숫자 이동에 더해 컷 사이 시간 생략을 알아볼 수 있도록 콘텐츠에 가로 방향 흐림·이동하는 주사선·추적 띠를 합성하고 화면 중앙에 흐릿한 빠른 재생 아이콘을 표시한다. 설명 문구는 표시하지 않으며 상단 시계·상태는 선명하게 유지한다. 전환 길이는 기존 `clockTransition`으로 지정한다.

기존 콘텐츠·문자 이력·채팅·지도는 전환 동안 유지하고 표시 시계만 생략 시간을 이동한다. 실제 이야기 시각이 연속이거나 전환 길이가 0인 컷에는 새 후처리를 표시하지 않는다. 효과 진행도는 프레임에서 계산하므로 부분 출력과 임의 탐색에서 같은 결과를 낸다.

같은 장면에 전환 2.5초를 적용한 5.5초 길이의 H.264/AAC 1920×1080 60fps MP4로 빠른 재생과 시계만 남기는 암전을 비교했고, 사용자가 빠른 재생 시안 A를 확정했다. 암전 시안의 구현·스타일 선택 필드는 정리했다. 실제 프레임에서 중앙 아이콘·잔상과 시계 선명도를 확인했으며 일반 blackout 프레임도 별도로 검증했다. 비교 화면은 네트워크 요청 없는 내장 영상으로 채팅 임시 폴더에 제공했다. 시안과 검증용 입력은 개발 자료에 포함하지 않는다.

`npm run build`, 시간 도약·수신/시계·정보 전환·채팅·화면 효과·기본 계약 테스트를 통과했다. 관련 요구는 F1, F2, F4, F5, N1, N2이며 PLAN의 P10에 대응한다. 공개 npm 배포는 진행하지 않았다.
