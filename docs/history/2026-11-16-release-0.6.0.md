# npm 0.6.0 배포

## 범위

세로 색상 막대 범례와 범례 모서리 위치 선택, 방송 안내의 작성 주체를 현황판 관리자로 명확히 한 창작 지침을 `0.6.0`으로 묶었다. 관련 요구는 F1, F3, F5, F6, N1, N2, N4이며 PLAN의 P4·P12에 대응한다. 기존 항목형 범례는 기본 표시를 유지하며 새 범례는 `layout: colorbar`·`position`·`unit`을 사용한다. 구현 범위와 지침 판단은 [범례·관리자 공지](2026-11-16-compact-legend-and-bulletins.md)에 기록했다.

## 배포 준비와 검증

패키지·잠금 파일·CLI 표시 버전을 `0.6.0`으로 맞췄다. 전체 테스트 86개, 타입 검사와 빌드가 통과했다. npm 공개 레지스트리의 기존 latest가 `0.5.1`이고 `0.6.0`이 미게시 상태임을 확인했다.

최종 tgz는 134개 파일, 8,389,970바이트다. 범례 빌드와 창작 스킬·README를 포함하며 소스·테스트·개발 문서·캐시 결과물은 포함하지 않는다. SHA-1은 `0604bd2f0628707e34cafe81fab01134cc01d37b`이며 무결성은 `sha512-3++m3GwY1paPmK/zNnH+A6zrVjSZtV/dXJZeqpn6tcnU/cYrqPEJ1AmpouUTK8gXKba5Tdg0BGwkSU6Vlg7nFg==`다. `npm publish`의 공개 게시·latest 태그 사전 검사를 통과했다.

별도 폴더의 tgz 설치본에서 CLI 버전, 기본 작품 초기화·검증, 그리드·색상 막대 작품 검증·프레임 상태 조회, JSON Schema와 README·내보낸 스킬의 원본 일치를 확인했다. 배포 검증 자료는 `.cache/release-0.6.0/`에 둔다. 실제 PNG는 이번 기능 구현 검증에서 확인했으며 배포 준비 과정에서 새 영상 출력은 반복하지 않았다.

## 게시 결과

npm 계정 `neuwnpmbox`의 로그인 인증과 별도 게시 본인 인증을 사용자가 완료한 뒤, 검증한 tgz를 `npm publish --access public --tag latest`로 게시했다. CLI는 `+ disaster-broadcast-studio@0.6.0`과 성공 종료 코드를 반환했으며 레지스트리 처리에 수분이 걸릴 수 있음을 안내했다.

후속 처리 뒤 공개 레지스트리에서 버전 `0.6.0`, `latest: 0.6.0`과 최종 tgz의 SHA-1·SHA-512 무결성 일치를 확인했다.
