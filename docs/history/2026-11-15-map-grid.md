# 범용 지도 그리드

강수 레이더처럼 행정경계와 무관한 색상 분포를 표시하기 위해 범용 `grid` 이벤트를 추가했다. 현황판은 개인이 운영하는 공개 정보 집계 서비스이며, 새로운 수치 패널·그래프·내부 시설 상태 화면은 추가하지 않았다. 지도 위 숫자·텍스트·격자선도 자동 생성하지 않는다. 관련 요구는 F1, F3, F5, F6, N1, N2이며 PLAN의 P12에 대응한다.

그리드는 기존 `assets`의 로컬 JSON을 참조한다. 파일은 WGS84 범위와 북→남·서→동 순서의 직사각형 셀 배열로 구성한다. 셀은 RGB·RGBA 색상 또는 투명한 null이며 최대 256×256이다. 범위·크기·색상을 로딩 때 검사하고 자산과 참조 이벤트를 포함해 오류를 반환한다. 날짜변경선을 가로지르는 범위는 지원하지 않는다.

셀별 좌표를 창작 AI가 추측하지 않도록 한 범위와 행·열로 위치를 결정한다. 실행 가능한 합성 분포 생성 코드 `examples/grid.mjs`를 창작 스킬에 동봉하고, 별도 파일을 생성해 시점별 이벤트로 교체하는 작성법을 안내했다. 예제는 실측·예보 자료가 아니며 실제 공개 자료의 출처와 구별한다. 실제 수집 API나 침수 시뮬레이션은 포함하지 않는다.

메인·보조 지도의 MapLibre 카메라로 셀 꼭짓점을 각각 투영한다. 같은 색의 가로 셀을 합쳐 그리며 픽셀 중심 기준으로 셀을 채워 기울어진 지도에서도 경계 잔선이 생기지 않게 했다. 카메라가 같으면 캔버스를 재사용하고 전체 불투명도·페이드는 콘텐츠 프레임에서 적용한다. 색면 위로 기존 지역 강조·선·마커를 합성한다. 시점별 교체·중첩·컷 이월·시간 도약 중 이전 화면 유지와 임의 탐색은 기존 타임라인을 따른다. 파일은 기존 미리보기 자산 감지에 연결하고 게시용 출처에 그리드로 기록한다.

검증 범위는 다음과 같다.

- 그리드·지도 효과·미리보기·기본 계약 테스트 29개와 TypeScript 빌드를 통과했다. 범위·행렬·색상 오류, 투명도와 결측 셀, 북쪽 첫 행, 잔선 없는 셀 경계, 뷰포트별 투영·자르기, 컷 이월·페이드·시간 도약·탐색·교체, 파일 수정·오류 중 마지막 정상 자료 유지·복구를 확인했다.
- 동봉 생성 코드로 96×72의 서로 다른 두 그리드 파일을 만들고 CLI 검증·JSON Schema 출력을 확인했다.
- 실제 Chromium/swangle PNG에서 카메라 회전·기울기·확대와 보조 지도, 라벨 없는 기존 마커의 중첩을 확인했다. 캔버스 셀 경계의 잔선을 제거한 출력도 확인했다.
- 570~689 프레임의 2초 구간을 H.264/AAC 1920×1080 60fps MP4로 출력했다. 시간 도약 뒤 새 색면으로 교체된 프레임을 추출해 확인했다.

검증 입력·그리드·프레임·구간 영상은 `.cache/grid-validation/`에 두며 배포물에 포함하지 않는다. 공개 npm 게시와 버전 변경은 수행하지 않았다. Windows/macOS와 독립 설치본 검증은 다음 배포 경계에서 확인한다.
