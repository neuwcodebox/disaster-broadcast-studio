# 작품 작업공간 구조

생성 코드와 직접 준비한 원본 자산은 `src/audio/`·`src/maps/`, 코드로 만든 음원과 합성 기록은 `output/audio/`, 그리드는 `output/maps/`에 모은다. 영상·프레임·검토 자료·게시용 출처도 `output/`에 저장한다. 재생성 가능한 결과 전체를 폴더 단위로 Git 추적에서 제외할 수 있는 구조다. 관련 요구는 F5, F6, N3이며 PLAN의 P5에 대응한다.

`init`은 위 폴더와 기존 YAML·작품 README를 생성한다. `.gitignore`는 생성하거나 수정하지 않는다. 로더는 계속 시나리오에 지정한 자산 경로를 사용하며 기존 작품의 파일을 이동하지 않는다. 현재 사용 안내·창작 스킬·음향 및 그리드 예제의 경로를 통일했다. README는 기존 초기화 설명과 예제의 경로를 수정했다.

작업공간·미리보기·그리드 계약 테스트 12개와 TypeScript 빌드를 통과했다. 중첩 폴더의 파일·심볼릭 링크 충돌 시 쓰기 전 실패, 기존 출력과 `.gitignore` 보존, 새 작업공간의 `.gitignore` 미생성을 확인했다. 실제 CLI로 `.cache/workspace-layout-check/`를 초기화하고 동봉 예제를 `src/maps/grid.mjs`에 두어 `output/maps/early.json`을 생성한 뒤 시나리오 참조와 검증을 확인했다. 공개 패키지 배포는 수행하지 않았다.
