# npm 0.4.1 배포

## 범위

사용자의 추가 수정 배포 요청에 따라 `dbs init`의 산출물 폴더 생성과 관련 사용 안내를 `0.4.1`로 묶었다. 관련 요구는 F5·F6, N3·N4이며 P4·P5의 초기화·패키지 사용 흐름에 해당한다. 초기화는 `output/`을 만들고 기존 산출물을 보존하며, 같은 이름의 파일이나 심볼릭 링크가 있으면 작품 파일 생성 전에 실패한다. 작품 README·CLI·창작 스킬의 명령 예제도 산출물 경로를 안내한다.

0.4.0 패키징 이후 정리한 소개·사용법 중심 README와 배포 준비 중 추가로 수정한 README(`839e8ad`)를 포함한다. 최종 버전 기준 커밋은 `867c8d4`다. 시나리오 형식과 렌더링 계약은 유지한다.

## 배포 전 검증

- 전체 테스트 77개, 타입 검사와 빌드가 통과했다. `output/`의 파일·심볼릭 링크 충돌 시 생성 전 실패와 기존 산출물 보존을 포함한다.
- 최종 tgz는 124개 파일, 8,382,559바이트다. `npm publish --dry-run --access public --tag latest`가 통과했고 패키징 결과와 무결성이 일치했다: `sha512-dqSUExVXd8kAFhtSYDDPQpA6ldtQH41I4uoELmXr9lsE8tSJ+jXsWn8GUaLhuMGqixcUnqB6jrqPSN4P5r03mQ==`.
- 새 `/tmp` 폴더에 tgz를 오프라인 설치해 `dbs --version`의 `0.4.1`, 초기화한 30초 작품의 경고 없는 검증, `audio/`·`audio-code/`·`output/` 생성을 확인했다.
- 설치본에서 기존 `output/film.mp4`의 보존과 `output` 파일 충돌 시 다른 파일을 만들지 않는 동작을 확인했다. 생성한 `output/`으로 JSON Schema와 게시용 출처를 출력했다.
- 동봉한 루트 README와 초기화용 README가 최종 소스와 일치했다. 소스·테스트·개발 문서·검증 결과는 배포물에서 제외했다. 검증 결과는 `.cache/release-0.4.1/`에 보관한다.
