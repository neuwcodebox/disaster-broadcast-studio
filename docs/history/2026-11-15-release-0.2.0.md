# npm 0.2.0 배포

## 범위와 버전

사용자의 버전 상향·npm 게시 요청에 따라 `0.1.1` 이후 추가된 웹 실시간 미리보기, 정보 변경 전환·점멸, 등급별 기본 효과음과 뉴스 기본 무음을 `0.2.0`으로 묶었다. 관련 요구는 F3~F5, N2, N3이며 P2·P3·P7의 공개 배포에 해당한다. 패키지·잠금 파일·CLI 버전을 함께 변경한 소스 기준 커밋은 `81dfef7`이다.

## 배포 전 검증

- 전체 테스트 50개, 타입 검사, 빌드가 통과했다.
- 최종 tgz는 109개 파일, 8,332,732바이트다. 미리보기 브라우저·서버 모듈, 지도·효과음·README 이미지·창작 스킬을 포함하며 소스·테스트·개발 문서는 제외했다.
- 동일 tgz의 `npm publish --dry-run --access public --tag latest`가 통과했다. 무결성 값은 `sha512-thZqze0b1YWnhgC1mrvqS6bbnELBubh4Z1NIRYIq6wi/A7Xcb4hI+VV6BhCFTvb69jb2B+QLWVhOPh/GLl2YcQ==`다.
- 별도 `/tmp` 폴더에 tgz를 오프라인 설치해 `dbs --version`의 `0.2.0`, 작품 초기화와 30초 작품의 경고 없는 검증을 확인했다.
- 설치본에서 웹 번들을 생성하고 미리보기 페이지·시나리오 API의 HTTP 200, 음원 Range 요청의 HTTP 206과 44바이트 응답, 서버 종료를 확인했다. 실제 브라우저 재생·PNG 회귀 검증 범위는 [웹 미리보기 이력](2026-11-15-browser-preview.md)을 따른다.

## 게시 결과

공개 레지스트리의 기존 `latest: 0.1.1`과 npm 계정 `neuwnpmbox`를 확인한 뒤 검증한 tgz를 게시했다. 사용자의 npm 브라우저 본인 인증 후 CLI가 성공했으며, npm 처리 대기를 거쳐 2026-11-15 18:13:07 KST에 캐시를 우회한 공개 조회로 `latest: 0.2.0`과 최종 tgz의 무결성 일치를 확인했다.

- 공개 주소: https://www.npmjs.com/package/disaster-broadcast-studio/v/0.2.0
- 새 `/tmp` 폴더에서 공개 레지스트리의 `disaster-broadcast-studio@latest`를 설치했다. 설치 잠금 파일의 버전 `0.2.0`·레지스트리 tgz 주소·무결성이 일치했고, `dbs --version`, `dbs init`, 생성한 30초 작품의 `dbs validate`가 경고 없이 통과했다.
