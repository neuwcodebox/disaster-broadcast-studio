# 재난방송실 — 기술 설계

## 구조와 책임

작품 YAML/JSON → 스키마·지역·자산 검증 → 프레임 타임라인 → React 방송 화면·음향 → Remotion 이미지/영상 출력으로 이어진다. 엔진은 이야기의 사실관계나 의도된 기관 간 모순을 판단하지 않는다.

| 경계 | 구현 | 관련 요구 |
| --- | --- | --- |
| 작품 계약 | `src/scenario.ts`: Zod strict 스키마, 60fps 변환, 참조·중복·연출 충돌 검증 | F1, F2, N3 |
| 외부 파일 | `src/load.ts`: YAML/JSON, 작품 기준 로컬 자산, GeoJSON, 읽기 시간 경고 | F1, F3, F5, N2, N4 |
| 시간 상태 | `src/timeline.ts`: 프레임의 컷·시계·누적 문자·활성 연출·카메라 | F2, F4, N2 |
| 지도 | `src/video/Map.tsx`: MapLibre 로컬 벡터 경계·강조·카메라·보조 지도 | F3, N1, N2 |
| 방송 | `src/video`: 방송 레이아웃, 문자 이력·방송 안내, 글꼴 로딩, 효과·음향을 컴포넌트·훅으로 분리 | F3, F4, N1 |
| 출력 | `src/render.ts`: 로컬 자산 준비·번들·동일 composition의 PNG/MP4, `src/output.ts`: 출력·부속 파일 준비·충돌 보호·정리 | F5, N2, N3 |
| 음원 생성 | `src/audio`: Tone.Offline·Remotion Artifact·PCM16 WAV와 합성 기록 | F4, F5, N2, N3 |
| CLI | `src/cli.ts`: init/validate/schema/regions/inspect/audio/frame/render/credits/skill | F5, F6, N3 |
| 창작 지원 | `skills/scenario-writing`: 독립 스킬과 정본 참고자료 | F6, N4 |

정확한 작품 필드·명령은 배포물에도 포함하는 [사용 계약](../skills/scenario-writing/references/format.md) 한 곳에서 관리한다. JSON Schema는 코드에서 `dbs schema`로 생성한다. 개발 문서에 같은 필드 목록을 복제하지 않는다.

## 시간과 상태

컷은 나열한 순서대로 프레임을 빈틈없이 이어 붙인다. 초는 `round(seconds * 60)`으로 정규화하고 컷 내부 시계는 `storyTime + localFrame / 60`이다. 컷 경계에서만 다음 이야기 시각으로 이동한다. 뒤로 가는 시각과 너무 짧아 0프레임이 되는 길이는 거부한다. 관련 요구: F1, F2, N2.

문자는 도착 이후 이력에 남고 정정은 별도 문자로 원 ID를 참조한다. 기간이 있는 연출은 반열린 구간 `[start,end)`에서 활성화된다. 컷 경계를 넘을 때는 `carry`를 명시한다. 카메라·뉴스·보조 지도·상태 표시줄·방송 안내는 동시 단일 제어이며 중첩을 오류로 반환한다. 지역·지점·소리·화면 효과는 병렬로 조합한다. 같은 프레임 이벤트 순서는 원본 배열 순서를 유지한다.

프레임 상태는 원본과 프레임 번호의 함수다. 순차 재생의 누적 React 상태에 의존하지 않는다. 카메라도 이전 완료 위치와 현재 보간을 프레임에서 다시 계산한다. 부분 렌더와 임의 탐색에 같은 함수가 쓰인다. 프레임 기준 볼륨·페이드와 침묵 구간을 평가하며 침묵 중에도 원음의 위치는 진행한다. 관련 요구: F2, F4, F5, N2.

## 지도·화면·자산

본문 약 66% 지도, 34% 문자 패널, 상단 상태 박스·시계, 하단 독립 뉴스를 사용한다. 검정·짙은 회색 바탕에 각진 구분선과 촘촘한 정보 위계를 사용한다. 색은 문자·상태·지도 강조에 절제해서 사용한다. 문자 카드는 내용 높이만 차지하며 빈 공간을 고정 높이로 늘리지 않는다. 첫 5초 오프닝에 제목과 허구 고지를 표시한다. 장문은 내용 손실 없이 페이지를 나누며 최신 문자와 이전 이력을 함께 보여준다.

정보 전환은 `src/video/transitions.ts`에서 콘텐츠 프레임으로 계산하며 약 0.45초 후 정착한다. 뉴스는 출처·시각·헤드라인을 함께 위로 교체하고 종료 시에도 퇴장한다. 문자 수신은 실제 카드 높이를 CSS grid로 펼쳐 이력을 밀어내며 이전 최신 카드의 크기도 함께 줄인다. 장문 페이지는 이전·다음 문안을 짧게 교차 전환한다. 상태는 유지 항목을 그대로 표시하고 바뀐 항목만 같은 칸에서 교체한다. 진입 후 1.8초 동안 3회 밝기가 내려갔다 돌아오며 배경·하단 선도 강조한다. 상태 해제·방송 안내 진입과 종료, 범례·보조 지도 진입에도 전환을 적용한다. 타이머·CSS 재생 애니메이션·이전 DOM 측정에 의존하지 않으며 시계 전환 중에는 콘텐츠와 효과를 함께 유지한다. 문자 이력도 등급 배지·왼쪽 테두리의 색상을 유지한다. 수신 최신순으로 표시하며 같은 시점에는 시나리오 배열에서 뒤에 작성한 문자를 위에 둔다. 패널 높이를 넘는 과거 항목은 아래쪽에 누적된다. 관련 요구: F3, N1, N4.

MapLibre GL JS를 사용한다. 현재 필요한 면·선·지점·카메라 표현은 MapLibre와 DOM 투영으로 충족하여 deck.gl을 추가하지 않았다. 행정경계는 기존 disaster-feed-web과 같은 SGIS/admdongkor 2026-07-01 원본에서 좌표 단순화 없이 시군구·시도로 병합한다. 기본 대한민국 육지와 시군구 강조에 같은 폴리곤을 사용한다. 북한은 WFP·OCHA의 상세 경계, 나머지 주변국은 Natural Earth 1:10m의 원래 해안선을 사용하며 기본 대한민국 배경 도형은 중복 표시하지 않는다. 경계는 gzip 자산으로 보관하고 GeoJSON 단순화 없이 MapLibre에 전달한다. 런타임에 원격 지도 타일이나 운영 disaster-feed API를 호출하지 않는다. [자산 출처·사용권](../assets/README.md)은 자산과 함께 배포한다.

카메라가 바뀌는 프레임은 MapLibre의 jumpTo 후 idle을 기다리고 기본 지도를 캡처한다. 같은 카메라에서는 기본 캡처를 유지한다. 실제 행정 경계를 MapLibre.project로 SVG 경로에 투영해 카메라별로 캐시하고 모든 좌표와 구멍을 유지한다. 채우기·윤곽선은 별도로 합성한다. 수신 효과는 이 SVG의 불투명도만 바꾸며 지도 소스·레이어·기본 캡처에 영향을 주지 않는다. 지도 오류는 cancelRender로 전달한다. IBM Plex Sans KR 400/600과 IBM Plex Mono 400의 CSS·폰트 파일은 설치된 Fontsource에서 로컬 공개 디렉터리로 복사하고 한글·고정폭 숫자 로딩 완료를 기다린다. 시각·수신 시간·수치에는 고정폭 숫자 글꼴을 사용한다. 기본 지역명·시설명은 표시하지 않는다. 작품이 명시한 선택적 지역·지점 캡션만 투영한다. 지역은 채우기 불투명도와 윤곽선 색·폭·불투명도를 독립적으로 설정한다. 모든 채우기 위에 윤곽선을 합성하며 같은 종류는 타임라인 순서를 따른다. 시간 지정 범례는 문구·색·기호만 받고 공간적 의미를 추론하지 않는다. 사용자 지정 영역·선은 MapLibre 투영을 공유하는 SVG로 표시하며 진행선은 프레임에서 길이를 계산한다. 소리도 작품 기준 로컬 파일을 복사한다. 자산 누락은 검증 단계에서 거부하며 잘못된 미디어·폰트·지도 로드는 렌더 단계에서 실패한다. 관련 요구: F3, F5, N2, N4.

후처리 `noise`, `scanlines`, `chromatic`, `dropout`은 프레임·시드·페이드로 결정하며 명시된 구간에만 합성한다. 흑백 잡음은 작은 캔버스를 확대하고, 주사선·누락 대역은 가벼운 레이어, 채널 분리는 SVG 필터를 사용한다. 기존 blackout·flash·interference 동작은 유지한다. 관련 요구: F4, N1, N2.

## 출력·실행 환경

Node.js 22+, TypeScript, React 19, Remotion 4.0.543, MapLibre 6.18.0, Zod 4, YAML 2를 사용한다. 설치 버전은 `package-lock.json`으로 고정한다. 영상 엔진을 직접 구현하지 않고 [Remotion renderer](https://www.remotion.dev/docs/renderer/render-media)와 [지도 통합 방식](https://www.remotion.dev/docs/maps)을 따른다. 관련 요구: F5, N3.

상태 이벤트는 문구·색상 목록만 받고 특정 경보 체계를 하드코딩하지 않는다. 방송 안내는 지도·문자 영역을 대체하고 시계·상태·뉴스를 유지한다. `inspect`는 같은 프레임 계산 결과를 렌더 없이 반환한다.

PNG 프레임, 포함 범위 MP4, 전체 MP4가 동일 composition과 props를 사용한다. 기본 영상은 1920×1080 60fps H.264/yuv420p, AAC 트랙을 포함한다. 출력별 `.credits.txt`에 제공자·출처·라이선스·가공 내용을, `.json`에 구조화된 출처와 프레임 범위를 기록한다. 상시 지도 출처 오버레이 대신 게시 설명에 동봉할 문안을 생성한다. 사용자 자산의 추가 조건은 작품별로 확인한다. 영상·음원 출력은 `withOutputFiles`로 목적지와 같은 파일시스템의 임시 디렉터리에 결과와 부속 파일을 준비한다. 모든 필수 파일을 확인한 뒤 부속 파일과 본 결과 순으로 게시하며 임시 디렉터리를 정리한다. 기본 모드는 기존 결과·부속 파일을 검사하고 배타적 하드 링크로 렌더 중 생긴 충돌도 보호한다. `--overwrite`는 파일별 rename으로 교체하며 전체 파일 집합의 일괄 교체를 보장하지 않는다. Chromium 경로와 WebGL 백엔드·동시 렌더 수를 지정할 수 있다. 최초 브라우저 준비를 제외한 렌더는 로컬에서 수행한다. 60fps 재생 규격과 실제 출력 속도는 별개다. 하드웨어가 다른 GPU의 픽셀 단위 일치는 보장하지 않는다. 관련 요구: F4, F5, N2.

## 수신·시간 전환과 종료 연출

문자 `regions`의 수신 강조는 테두리를 유지하고 기본 2.4초 동안 채우기를 3회 부드럽게 점멸한다. 상태와 수신 지역은 `notificationPulse`의 프레임 기준 파형을 공유한다. 길이·색 변경과 끄기를 지원한다. 일반 region은 fadeIn/fadeOut과 완만한 채우기 pulse를 지원한다. 공통 수신음은 패키지의 CC0 합성 WAV이며 사용자 음원·끄기·silence를 지원한다.

`clockTransition`은 사건 epoch와 표시 epoch를 분리한다. 이전 콘텐츠를 유지한 채 기존 상단 시계를 강조하고 숫자를 이동시킨 뒤 도착 시각을 유지한다. 전환 후 정확한 현재 시각으로 실시간 재생한다. 새 정보 시점은 작품이 정한다. 반복 문자도 일반 alert이며 동일 내용의 연속 반복은 중간 읽기 간격 경고에서 제외한다. 화면·음향 종료는 blackout/silence의 시점으로 정한다. 관련 요구: F1~F5, N1, N2.

## Tone.js 음원 생성

`dbs audio`는 작성자가 확인한 로컬 ES 모듈을 번들해 기존 Remotion Chromium에서 `Tone.Offline`으로 실행한다. Tone.js 15.1.22를 고정하며 콜백에 Tone·OfflineContext·길이·PCM 설정·시드 난수·로컬 샘플 경로 함수를 제공한다. `--assets`는 선택한 로컬 샘플 폴더를 번들에 포함한다. 브라우저의 Artifact로 PCM16 WAV와 통계를 돌려받아 성공 시 결과 파일로 이동한다. 임시 번들·부분 WAV는 정리하고 오류는 CLI 실패로 전달한다. 출력 옆 기록에 실제 Tone/Chromium 버전·시드·샘플레이트·채널·길이·피크·클리핑을 보존한다. 난수는 Tone 로딩 전 초기화하고 모듈 함수에도 시드 기반 생성기를 제공한다. 동일 환경 재현을 목표로 하며 다른 Web Audio 구현의 바이트 일치까지 보장하지 않는다. 합성은 영상 출력과 분리되어 기존 파일 기반 오디오 타임라인을 그대로 사용한다. 관련 요구: F4, F5, N2, N3.

## 작품 초기화와 스킬 배포

`dbs init [directory]`는 YAML·작품 README·음향 폴더를 생성한다. 모든 충돌 경로를 먼저 검사하고 배타적 쓰기로 기존 사용자 파일을 보호한다. 스킬은 사용자 공통 범위에 Vercel skills로 GitHub 경로에서 설치·갱신한다. 작품마다 자동 복사하거나 자체 갱신 관리자를 만들지 않는다. npm 동봉 스킬의 `dbs skill --out`은 오프라인·수동 전달용 내보내기로 유지한다. GitHub 주소로 직접 읽으면 스킬 목록에 설치되지는 않는다. 관련 요구: F5, F6, N3.

## 패키징과 유지보수

npm 패키지 `disaster-broadcast-studio`, 실행명 `dbs`로 구성한다. 빌드된 JS, 지도 자산, 독립 스킬·참고자료를 포함한다. `dbs skill --out`으로 스킬 전체를 별도 워크스페이스에 복사할 수 있다. 실제 작품은 패키지나 개발 저장소에 넣지 않는다. 공개 npm 게시는 별도 승인 후 수행한다. 관련 요구: F5, F6, N3.

빠른 계약 테스트는 시간·탐색·참조·충돌·정정·페이지 보존·외부 파일 경계와 출력·부속 파일 보호·실패 정리를 확인한다. 기관·음원 참조는 사전에 직접 선언한 키만 허용하고, 지역·음원·화면 효과는 길이를 넘는 페이드를 거부한다. 문자 읽기 시간은 실제 5초 오프닝을 제외해 계산한다. 실제 프레임·짧은 구간·전체 영상과 외부 패키지 설치는 릴리스 경계에서 확인한다. OS별 그래픽 환경은 실제 실행 환경별로 구분해 기록한다. 스키마 변경은 실제 사용처가 생긴 뒤 영향과 변환을 판단하며 가상 호환 계층을 미리 만들지 않는다.
