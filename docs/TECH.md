# 재난방송실 — 기술 설계

## 구조와 책임

작품 YAML/JSON → 스키마·지역·자산 검증 → 프레임 타임라인 → React 방송 화면·음향 → Remotion 이미지/영상 출력으로 이어진다. 엔진은 이야기의 사실관계나 의도된 기관 간 모순을 판단하지 않는다.

## 시간과 상태

컷은 나열한 순서대로 프레임을 빈틈없이 이어 붙인다. 초는 `round(seconds * 60)`으로 정규화하고 컷 내부 시계는 `storyTime + localFrame / 60`이다. 컷 경계에서만 다음 이야기 시각으로 이동한다. 뒤로 가는 시각과 너무 짧아 0프레임이 되는 길이는 거부한다. 관련 요구: F1, F2, N2.

문자는 도착 이후 이력에 남는다. 정정 안내도 일반 문자이며 작성한 본문만으로 전달한다. 기간이 있는 연출은 반열린 구간 `[start,end)`에서 활성화된다. 컷 경계를 넘을 때는 `carry`를 명시한다. 카메라·뉴스·보조 지도·상태 표시줄·방송 안내는 동시 단일 제어이며 중첩을 오류로 반환한다. 지역·지점·소리·화면 효과는 병렬로 조합한다. 같은 프레임 이벤트 순서는 원본 배열 순서를 유지한다.

프레임 상태는 원본과 프레임 번호의 함수다. 순차 재생의 누적 React 상태에 의존하지 않는다. 카메라도 이전 완료 위치와 현재 보간을 프레임에서 다시 계산한다. 부분 렌더와 임의 탐색에 같은 함수가 쓰인다. 프레임 기준 볼륨·페이드와 침묵 구간을 평가하며 침묵 중에도 원음의 위치는 진행한다. 관련 요구: F2, F4, F5, N2.

음원 `loop`와 `playbackRate`는 Remotion Audio의 동일 속성으로 연결한다. `trimBefore`는 속도와 무관하게 원본 offset을 60fps 프레임으로 변환하며, 반복 범위는 offset부터 원본 끝까지다. 외부 Sequence가 영상 시간 기준 이벤트 길이를 제한한다. 볼륨은 전체 영상 프레임에서 계산한 숫자로 전달하므로 반복 내부 프레임에 따라 페이드가 다시 시작되지 않는다. 침묵은 볼륨만 0으로 만들고 원본 위치·반복·속도에는 영향을 주지 않는다. 관련 요구: F4, F5, N2.

## 지도·화면·자산

본문 폭의 60%는 지도, 40%는 문자 패널로 사용하며 상단 상태 박스·시계와 하단 독립 뉴스를 표시한다. `src/video/layout.ts`가 공통 상단·하단 높이와 문자 패널 폭을 정의한다. 검정·짙은 회색 바탕에 각진 구분선과 촘촘한 정보 위계를 사용한다. 색은 문자·상태·지도 강조에 절제해서 사용한다. 문자 카드는 내용 높이만 차지하며 빈 공간을 고정 높이로 늘리지 않는다. 첫 5초 오프닝에 제목과 허구 고지를 표시한다. 각 문안의 전문을 한 번에 표시하며 최신 문자와 이전 이력을 함께 보여준다. 재난문자·뉴스 본문은 40px, 이전 문자는 32px, 채팅은 28px이며 시각·발신자·등급과 지도 라벨도 함께 키운다. 854px 가로 축소본에서 핵심 본문은 약 18px에 해당한다. 화면에 들어갈 만큼 짧게 작성하도록 스키마가 길이·명시적 줄 수를 검증하고 문자 컴파일 시 발신자 접두사를 포함한 분량도 확인한다.

정보 전환은 `src/video/transitions.ts`에서 콘텐츠 프레임으로 계산하며 약 0.45초 후 정착한다. 뉴스는 출처·시각·헤드라인을 함께 위로 교체하고 종료 시에도 퇴장한다. 문자 수신은 실제 카드 높이를 CSS grid로 펼쳐 이력을 밀어내며 이전 최신 카드의 크기도 함께 줄인다. 상태는 유지 항목을 그대로 표시하고 바뀐 항목만 같은 칸에서 교체한다. 진입 후 1.8초 동안 3회 밝기가 내려갔다 돌아오며 배경·하단 선도 강조한다. 상태 해제·방송 안내 진입과 종료, 범례·보조 지도 진입에도 전환을 적용한다. 타이머·CSS 재생 애니메이션·이전 DOM 측정에 의존하지 않으며 시계 전환 중에는 콘텐츠와 효과를 함께 유지한다. 문자 이력도 등급 배지·왼쪽 테두리의 색상을 유지한다. 수신 최신순으로 표시하며 같은 시점에는 시나리오 배열에서 뒤에 작성한 문자를 위에 둔다. 패널 높이를 넘는 과거 항목은 아래쪽에 누적된다. 관련 요구: F3, N1, N4.

MapLibre GL JS를 사용한다. 현재 필요한 면·선·지점·카메라 표현은 MapLibre와 DOM 투영으로 충족하여 deck.gl을 추가하지 않았다. 행정경계는 기존 disaster-feed-web과 같은 SGIS/admdongkor 2026-07-01 원본에서 좌표 단순화 없이 시군구·시도로 병합한다. 기본 대한민국 육지와 시군구 강조에 같은 폴리곤을 사용한다. 북한은 WFP·OCHA의 상세 경계, 나머지 주변국은 Natural Earth 1:10m의 원래 해안선을 사용하며 기본 대한민국 배경 도형은 중복 표시하지 않는다. 경계는 gzip 자산으로 보관하고 GeoJSON 단순화 없이 MapLibre에 전달한다. 런타임에 원격 지도 타일이나 운영 disaster-feed API를 호출하지 않는다. [자산 출처·사용권](../assets/README.md)은 자산과 함께 배포한다.

카메라가 바뀌는 프레임은 MapLibre의 jumpTo 후 idle을 기다리고 기본 지도를 캡처한다. 같은 카메라에서는 기본 캡처를 유지한다. 실제 행정 경계를 MapLibre.project로 SVG 경로에 투영해 카메라별로 캐시하고 모든 좌표와 구멍을 유지한다. 채우기·윤곽선은 별도로 합성한다. 수신 효과는 이 SVG의 불투명도만 바꾸며 지도 소스·레이어·기본 캡처에 영향을 주지 않는다. 지도 오류는 cancelRender로 전달한다. IBM Plex Sans KR 400/600과 IBM Plex Mono 400의 CSS·폰트 파일은 설치된 Fontsource에서 로컬 공개 디렉터리로 복사하고 한글·고정폭 숫자 로딩 완료를 기다린다. 시각·수신 시간·수치에는 고정폭 숫자 글꼴을 사용한다. 기본 지역명·시설명은 표시하지 않는다. 작품이 명시한 선택적 지역·지점 캡션만 투영한다. 지역은 채우기 불투명도와 윤곽선 색·폭·불투명도를 독립적으로 설정한다. 모든 채우기 위에 윤곽선을 합성하며 같은 종류는 타임라인 순서를 따른다. 시간 지정 범례는 문구·색·기호만 받고 공간적 의미를 추론하지 않는다. 사용자 지정 영역·선은 MapLibre 투영을 공유하는 SVG로 표시하며 진행선은 프레임에서 길이를 계산한다. 소리도 작품 기준 로컬 파일을 복사한다. 자산 누락은 검증 단계에서 거부하며 잘못된 미디어·폰트·지도 로드는 렌더 단계에서 실패한다. 관련 요구: F3, F5, N2, N4.

`src/video/map/effects.tsx`는 구면 거리로 계산한 km 반경 원, 반복 확산 원·지점, 점선 흐름·진행·페이드를 순수 함수로 평가한다. 원은 96분할 지리 다각형으로 투영하고, 반복 확산으로 좌표가 바뀌면 기본 지도 캡처를 유지한 채 SVG 투영만 갱신한다. 지도 지원 위도 ±85도를 벗어나는 원은 컴파일 시 거부한다. 지점 링은 화면 픽셀 크기를 유지하며 지리 반경과 구별한다. 점선 흐름은 프레임 기준 dash offset이며 메인·보조 지도의 진행 마스크 ID를 분리한다. 모든 지도 연출은 콘텐츠 프레임을 사용해 시계 전환 중 멈춘다. 관련 요구: F3, F4, N2.

`grid`는 기존 자산 사전에서 로컬 JSON을 참조한다. `src/grid.ts`가 WGS84 범위·직사각형 행렬·RGB/RGBA/null을 검증하고 로더는 참조된 파일을 자산별로 한 번 읽어 방송 props에 넣는다. 음원 공개 경로에는 복사하지 않는다. `src/video/map/grid.tsx`는 북→남·서→동의 경위도 균등 격자에서 같은 색의 가로 셀을 합치고 각 꼭짓점을 해당 MapLibre 카메라로 투영해 Canvas 2D에 그린다. 카메라가 같으면 캔버스를 재사용하고 불투명도·페이드는 콘텐츠 프레임 기준 CSS로 적용하므로 기본 지도 캡처나 격자를 매 프레임 다시 그리지 않는다. 색면은 지역 강조·선·마커 아래에 합성한다. 관측별 교체는 기존 구간 이벤트를 사용하며 자동 공간·시간 보간을 하지 않는다. 미리보기는 기존 자산 감지로 JSON 수정·오류·복구를 반영한다. 실행 가능한 합성 격자 예제를 창작 스킬에 동봉한다. 관련 요구: F1, F3, F5, F6, N1, N2.

후처리 `noise`, `scanlines`, `chromatic`, `dropout`, `blur`, `desaturate`, `vignette`, `flicker`, `jitter`, `vhs`는 콘텐츠 프레임·시드·페이드로 결정하며 명시된 구간에만 합성한다. 같은 효과의 강도는 합산 후 1로 제한한다. 흑백 잡음은 작은 캔버스를 확대하고, 주사선·누락 대역·비네트는 가벼운 레이어, 채널 분리·VHS 수평 추적 왜곡은 SVG 필터, 흐림·흑백·명도는 CSS 필터를 사용한다. 흔들림은 시드 기반 translate로 적용한다. 검정 루트 내부의 콘텐츠·후처리 단계 위에 blackout·flash·기존 interference를 이벤트 순서대로 합성하고 오프닝은 마지막에 표시한다. shutdown의 검정 유지 단계에는 새 후처리를 끄며, 전체 강도 0에서는 필터·변형을 적용하지 않는다. 시계 전환 중 기존 후처리와 종료 연출도 유지된 콘텐츠 프레임으로 평가한다. 관련 요구: F2, F4, N1, N2.

### 스트리밍 채팅

`chat` 구간 이벤트가 있을 때 오른쪽 문자 영역 아래 260px을 채팅에 배정하고 나머지 약 71% 높이는 문자 이력에 사용한다. 채팅은 재난문자보다 작은 제목·본문과 좁은 메시지 간격으로 보조 정보의 위계를 유지한다. 지도·뉴스·시계 크기는 유지하며 방송 안내는 채팅까지 덮는다. `chat-message`는 패널 ID를 참조하는 단발 이벤트다. 컴파일 시 참조 타입·활성 구간·패널 중첩을 검사하고, `stateAt`의 `chat`은 콘텐츠 프레임까지 수신한 해당 패널의 대화만 시간순으로 반환한다. 시계 전환 중에는 다른 정보와 함께 멈춘다.

`src/video/Chat.tsx`는 최근 메시지를 아래에 정렬하고 새 메시지 높이를 프레임 기반 CSS grid로 펼쳐 과거 대화를 위로 밀어낸다. DOM 측정·스크롤 상태·타이머·원격 서비스에 의존하지 않는다. 화면 밖 대화는 위에서 가리며 렌더할 DOM은 최근 12개로 제한한다. `inspect`에는 전체 수신 대화를 보존한다. 닉네임과 본문은 길이·단일 행 입력을 검증하고 화면에서는 본문을 줄바꿈해 표시한다. 기본 무음이며 별도 플랫폼 로고·입력창·가공한 시청자 수는 표시하지 않는다. 관련 요구: F1, F2, F5, F7, N1, N2.

## 출력·실행 환경

Node.js 22+, TypeScript, React 19, Remotion 4.0.543, MapLibre 6.18.0, Zod 4, YAML 2를 사용한다. 설치 버전은 `package-lock.json`으로 고정한다. 영상 엔진을 직접 구현하지 않고 [Remotion renderer](https://www.remotion.dev/docs/renderer/render-media)와 [지도 통합 방식](https://www.remotion.dev/docs/maps)을 따른다. 관련 요구: F5, N3.

상태 이벤트는 문구·색상 목록만 받고 특정 경보 체계를 하드코딩하지 않는다. 방송 안내는 지도·문자 영역을 대체하고 시계·상태·뉴스를 유지한다. `inspect`는 같은 프레임 계산 결과를 렌더 없이 반환한다.

`preview`는 `127.0.0.1`에 HTTP 서버를 열고 같은 `Broadcast`를 버전이 일치하는 `@remotion/player`로 재생한다. 기존 Remotion bundler의 브라우저 진입점만 교체해 별도 개발 서버 의존성을 추가하지 않는다. 정적 자산과 방송 props 준비는 이미지·영상 출력과 공유한다. 시나리오 내용과 현재 선언한 사용자 지도·음원의 파일 메타데이터를 주기적으로 비교하고 변경 시 기존 로더로 검증한다. 잘못된 문서·누락 파일은 오류로 표시하며 마지막 정상 props와 자산을 유지한다. 정상 갱신은 Player를 다시 마운트해 지도까지 복원하며 현재 프레임을 새 길이로 제한하고 일시정지한다. 음원 URL은 갱신별로 분리해 브라우저 캐시를 피하고 종료 시 임시 번들과 자산을 정리한다. 준비된 파일만 제공하고 오디오 Range 요청을 지원한다. 동시 음향 수에 맞춰 Player의 공유 오디오 태그를 준비한다. 지도 초기화·글꼴 로딩은 렌더 대기와 Player 버퍼 대기를 함께 사용한다. 웹 재생에서는 MapLibre 캔버스를 직접 표시하고 카메라·SVG 투영을 함께 갱신하며 매 프레임 idle 대기·캔버스 읽기를 피한다. 이미지·영상 출력은 기존의 idle 후 캡처를 유지한다. MP4 인코딩·Headless Chromium 준비는 필요 없고 재생 성능은 브라우저·GPU에 따른다. 관련 요구: F5, N2, N3.

PNG 프레임, 포함 범위 MP4, 전체 MP4가 동일 composition과 props를 사용한다. 기본 영상은 1920×1080 60fps H.264/yuv420p, AAC 트랙을 포함한다. 출력별 `.credits.txt`에 제공자·출처·라이선스·가공 내용을, `.json`에 구조화된 출처와 프레임 범위를 기록한다. 상시 지도 출처 오버레이 대신 게시 설명에 동봉할 문안을 생성한다. 사용자 자산의 추가 조건은 작품별로 확인한다. 영상·음원 출력은 `withOutputFiles`로 목적지와 같은 파일시스템의 임시 디렉터리에 결과와 부속 파일을 준비한다. 모든 필수 파일을 확인한 뒤 부속 파일과 본 결과 순으로 게시하며 임시 디렉터리를 정리한다. 기본 모드는 기존 결과·부속 파일을 검사하고 배타적 하드 링크로 렌더 중 생긴 충돌도 보호한다. `--overwrite`는 파일별 rename으로 교체하며 전체 파일 집합의 일괄 교체를 보장하지 않는다. Chromium 경로와 WebGL 백엔드·동시 렌더 수를 지정할 수 있다. 최초 브라우저 준비를 제외한 렌더는 로컬에서 수행한다. 60fps 재생 규격과 실제 출력 속도는 별개다. 하드웨어가 다른 GPU의 픽셀 단위 일치는 보장하지 않는다. 관련 요구: F4, F5, N2.

## 수신·시간 전환과 종료 연출

문자 `regions`의 수신 강조는 테두리를 유지하고 기본 2.4초 동안 채우기를 3회 부드럽게 점멸한다. 상태와 수신 지역은 `notificationPulse`의 프레임 기준 파형을 공유한다. 길이·색 변경과 끄기를 지원한다. 일반 region은 fadeIn/fadeOut과 완만한 채우기 pulse를 지원한다. 기본 효과음은 패키지의 CC0 합성 WAV다. `src/notifications.ts`의 단일 목록이 등급·이벤트별 파일·길이·볼륨을 정의하고 로더는 사용되는 파일만 연결한다. 안전안내는 0.55초의 휴대폰 진동형 두 번 떨림, 긴급재난 2.4초, 위급재난 4.2초이며 뒤의 두 등급은 두 주파수가 겹치는 경보와 반복 패턴으로 구분한다. 상태는 등장·실제 항목 변경·해제 때 화면 교체 시작에 0.3초의 동일 음높이 전자음 두 번이 재생되고 인접한 동일 항목에는 반복하지 않는다. 교체·점멸 애니메이션은 유지한다. 방송 안내는 시작 때 크고 묵직한 두 번의 신호로 주의를 환기하며 총 1초다. 뉴스의 `sound` 기본값은 `false`이며 명시적으로 켠 경우에만 시작 때 울린다. 네 이벤트의 `sound`는 기본음·사용자 음원·끄기를 공유하고 `silence`는 모든 음향을 음소거한다. 음원 끝은 영상 끝으로 제한하며 관련 요구는 F4, N2다.

`clockTransition`은 사건 epoch와 표시 epoch를 분리한다. 이전 콘텐츠를 유지한 채 기존 상단 시계를 강조하고 숫자를 이동시킨 뒤 도착 시각을 유지한다. 실제 생략 시간이 있는 전환에는 `src/video/TimeJump.tsx`가 콘텐츠의 가로 방향 흐림·이동하는 주사선과 추적 띠·화면 중앙의 흐릿한 빠른 재생 아이콘을 합성한다. 상단 시계·상태는 흐림에서 제외한다. 효과는 전환 프레임으로 부드럽게 나타나고 도착 시각 유지 단계에 사라지며 임의 탐색에서도 동일하다. 전환 후 정확한 현재 시각으로 실시간 재생한다. 새 정보 시점은 작품이 정한다. 반복 문자도 일반 alert이며 동일 내용의 연속 반복은 중간 읽기 간격 경고에서 제외한다. 화면·음향 종료는 blackout/silence의 시점으로 정한다. 관련 요구: F1~F5, N1, N2.

## Tone.js 음원 생성

`dbs audio`는 작성자가 확인한 로컬 ES 모듈을 번들해 기존 Remotion Chromium에서 `Tone.Offline`으로 실행한다. Tone.js 15.1.22를 고정하며 콜백에 Tone·OfflineContext·길이·PCM 설정·시드 난수·로컬 샘플 경로 함수를 제공한다. `--assets`는 선택한 로컬 샘플 폴더를 번들에 포함한다. 브라우저의 Artifact로 PCM16 WAV와 통계를 돌려받아 성공 시 결과 파일로 이동한다. 임시 번들·부분 WAV는 정리하고 오류는 CLI 실패로 전달한다. 출력 옆 기록에 실제 Tone/Chromium 버전·시드·샘플레이트·채널·길이·피크·클리핑을 보존한다. 난수는 Tone 로딩 전 초기화하고 모듈 함수에도 시드 기반 생성기를 제공한다. 동일 환경 재현을 목표로 하며 다른 Web Audio 구현의 바이트 일치까지 보장하지 않는다. 합성은 영상 출력과 분리되어 기존 파일 기반 오디오 타임라인을 그대로 사용한다. 관련 요구: F4, F5, N2, N3.

## 작품 초기화와 스킬 배포

창작 스킬의 본문은 작성 주체의 정보·환경·권한·목적·수신자와 시청자의 관점을 집필 전제로 둔다. `references/direction.md`는 공개 정보 스트리밍 서비스라는 현황판의 역할과 매체별 전달 범위, `news-writing.md`는 기자의 취재 환경과 보도 형태, `audio.md`는 소리의 출처·전달 경로와 시청 환경에서의 의미를 다룬다. `status-systems.md`는 상태바에 쓸 실재하는 공식 체계의 확인 기준과 개별 조치·상황 보도와의 구별을 다룬다. 이 판단은 창작 지침이며 엔진 스키마의 사실관계 검증으로 강제하지 않는다. 관련 요구: F6.

`response-system.md`는 중앙·지방·현장 조직과 법정 권한, 상황보고·매뉴얼·대피·통제의 공통 틀을 제공한다. `field-and-infrastructure-response.md`는 침수·산불·화재·붕괴와 전력·통신·수도 장애, `health-and-hazard-response.md`는 원인불명 집단발병·감염병·화학사고·방사선비상의 기관별 대응을 다룬다. 스킬과 참고자료 색인에서 사건별로 찾아가며 기존 경보 수치·문자 문안을 중복하지 않는다. 공개 법령의 확인 판본, 매뉴얼·안내의 작성 시점, 실제 대응 사례와 창작 적용을 구별해 기관별 병렬 대응과 공개 정보의 시간차를 설계하도록 한다. 관련 요구: F6, P4.

`war-and-emergency-system.md`는 통합방위·동원·징발·전쟁·계엄·긴급명령, `cbrn-and-terror-response.md`는 화생방공격·테러 의심과 관계기관 지원·주민 보호를 다룬다. `civil-defense.md`의 공식 경보 본문과 역할을 나눠 연결한다. `alert-examples.md`의 실제 문자와 `headline-examples.md`의 실제 제목은 날짜·직접 출처·전문/발췌를 붙여 실제 기록과 허구 문안을 구별한다. 사건 자료에서 문안 사례로 이어갈 수 있도록 관련 자료를 상호 연결한다. 관련 요구: F6, P4.

`dbs init [directory]`는 YAML·작품 README와 `audio/`·`audio-code/`·`output/`을 생성한다. 작품이 참조할 음원·합성 기록과 생성 코드는 음향 폴더에, 영상·프레임·검토 자료·게시용 출처 등 산출물은 `output/`에 모은다. 작품 README와 스킬의 CLI 예제는 작품 폴더에서 `--out output/...`을 지정하며 부속 기록은 결과 옆에 둔다. 모든 충돌 경로를 먼저 검사하고 배타적 쓰기로 기존 사용자 파일을 보호한다. 스킬은 사용자 공통 범위에 Vercel skills로 GitHub 경로에서 설치·갱신한다. 작품마다 자동 복사하거나 자체 갱신 관리자를 만들지 않는다. npm 동봉 스킬의 `dbs skill --out`은 오프라인·수동 전달용 내보내기로 유지한다. GitHub 주소로 직접 읽으면 스킬 목록에 설치되지는 않는다. 관련 요구: F5, F6, N3.

## 패키징과 유지보수

npm 패키지 `disaster-broadcast-studio`, 실행명 `dbs`로 구성한다. 빌드된 JS, 지도 자산, 독립 스킬·참고자료를 포함한다. `dbs skill --out`으로 스킬 전체를 별도 워크스페이스에 복사할 수 있다. 실제 작품은 패키지나 개발 저장소에 넣지 않는다. 공개 npm 게시는 별도 승인 후 수행한다. 관련 요구: F5, F6, N3.

빠른 계약 테스트는 시간·탐색·참조·충돌·전문 유지·외부 파일 경계와 출력·부속 파일 보호·실패 정리를 확인한다. 기관·음원 참조는 사전에 직접 선언한 키만 허용하고, 지역·음원·화면 효과는 길이를 넘는 페이드를 거부한다. 문자 읽기 경고는 실제 5초 오프닝을 제외하고 최소 8초·초당 8자 기준으로 계산한다. 본문에는 자동 분할·페이지 번호·정정 연결 표기를 생성하지 않는다. 실제 프레임·짧은 구간·전체 영상과 외부 패키지 설치는 릴리스 경계에서 확인한다. OS별 그래픽 환경은 실제 실행 환경별로 구분해 기록한다. 스키마 변경은 실제 사용처가 생긴 뒤 영향과 변환을 판단하며 가상 호환 계층을 미리 만들지 않는다.
