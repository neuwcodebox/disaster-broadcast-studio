# 재난방송실 — 기술 설계

## 구조와 책임

작품 YAML/JSON → 스키마·지역·자산 검증 → 프레임 타임라인 → React 방송 화면·음향 → Remotion 이미지/영상 출력으로 이어진다. 엔진은 이야기의 사실관계나 의도된 기관 간 모순을 판단하지 않는다.

| 경계 | 구현 | 관련 요구 |
| --- | --- | --- |
| 작품 계약 | `src/scenario.ts`: Zod strict 스키마, 60fps 변환, 참조·중복·연출 충돌 검증 | F1, F2, N3 |
| 외부 파일 | `src/load.ts`: YAML/JSON, 작품 기준 로컬 자산, GeoJSON, 읽기 시간 경고 | F1, F3, F5, N2, N4 |
| 시간 상태 | `src/timeline.ts`: 프레임의 컷·시계·누적 문자·활성 연출·카메라 | F2, F4, N2 |
| 지도 | `src/video/Map.tsx`: MapLibre 로컬 벡터 경계·강조·카메라·보조 지도 | F3, N1, N2 |
| 방송 | `src/video/Broadcast.tsx`: 한글 레이아웃·문자 페이지·뉴스·효과·음향 | F3, F4, N1 |
| 출력 | `src/render.ts`: 로컬 자산 준비·번들·동일 composition의 PNG/MP4·원자적 결과 이동 | F5, N2, N3 |
| CLI | `src/cli.ts`: validate/schema/regions/frame/render/skill | F5, F6, N3 |
| 창작 지원 | `skills/scenario-writing`: 독립 스킬과 정본 참고자료 | F6, N4 |

정확한 작품 필드·명령은 배포물에도 포함하는 [사용 계약](../skills/scenario-writing/references/format.md) 한 곳에서 관리한다. JSON Schema는 코드에서 `dbs schema`로 생성한다. 개발 문서에 같은 필드 목록을 복제하지 않는다.

## 시간과 상태

컷은 나열한 순서대로 프레임을 빈틈없이 이어 붙인다. 초는 `round(seconds * 60)`으로 정규화하고 컷 내부 시계는 `storyTime + localFrame / 60`이다. 컷 경계에서만 다음 이야기 시각으로 이동한다. 뒤로 가는 시각과 너무 짧아 0프레임이 되는 길이는 거부한다. 관련 요구: F1, F2, N2.

문자는 도착 이후 이력에 남고 정정은 별도 문자로 원 ID를 참조한다. 기간이 있는 연출은 반열린 구간 `[start,end)`에서 활성화된다. 컷 경계를 넘을 때는 `carry`를 명시한다. 카메라·뉴스·보조 지도는 동시 단일 제어이며 중첩을 오류로 반환한다. 지역·지점·소리·화면 효과는 병렬로 조합한다. 같은 프레임 이벤트 순서는 원본 배열 순서를 유지한다.

프레임 상태는 원본과 프레임 번호의 함수다. 순차 재생의 누적 React 상태에 의존하지 않는다. 카메라도 이전 완료 위치와 현재 보간을 프레임에서 다시 계산한다. 부분 렌더와 임의 탐색에 같은 함수가 쓰인다. 프레임 기준 볼륨·페이드와 침묵 구간을 평가하며 침묵 중에도 원음의 위치는 진행한다. 관련 요구: F2, F4, F5, N2.

## 지도·화면·자산

본문 약 66% 지도, 34% 문자 패널, 상단 제목·시계, 하단 독립 뉴스를 사용한다. 검정·회색·흰색을 기본으로 지역의 명시적 강조에만 경보색을 쓴다. 첫 3초 오프닝에 제목과 허구 고지를 표시한다. 장문은 내용 손실 없이 페이지를 나누며 최신 문자와 이전 이력을 함께 보여준다. 페이지와 이력 순환도 프레임 기준이다. 관련 요구: F3, N1, N4.

MapLibre GL JS를 사용한다. 현재 필요한 면·선·지점·카메라 표현은 MapLibre와 DOM 투영으로 충족하여 deck.gl을 추가하지 않았다. 기본 경계는 기존 disaster-feed-web의 2026-07-01 시군구 GeoJSON, 배경은 Natural Earth다. 런타임에 원격 지도 타일이나 운영 disaster-feed API를 호출하지 않는다. [자산 출처·사용권](../assets/README.md)은 자산과 함께 배포한다.

지도는 프레임마다 `jumpTo`와 GeoJSON 레이어 갱신 후 `idle`을 기다린다. WebGL 캡처 버퍼를 유지하며 지도 오류는 Remotion `cancelRender`로 출력 실패가 된다. Noto Sans KR 400/700 CSS와 필요한 폰트 파일은 설치된 Fontsource에서 로컬 공개 디렉터리로 복사하고 한글 로딩 완료를 기다린다. 소리도 작품 기준 로컬 파일을 복사한다. 자산 누락은 검증 단계에서 거부하며 잘못된 미디어·폰트·지도 로드는 렌더 단계에서 실패한다. 관련 요구: F3, F5, N2, N4.

## 출력·실행 환경

Node.js 22+, TypeScript, React 19, Remotion 4.0.543, MapLibre 6.18.0, Zod 4, YAML 2를 사용한다. 설치 버전은 `package-lock.json`으로 고정한다. 영상 엔진을 직접 구현하지 않고 [Remotion renderer](https://www.remotion.dev/docs/renderer/render-media)와 [지도 통합 방식](https://www.remotion.dev/docs/maps)을 따른다. 관련 요구: F5, N3.

PNG 프레임, 포함 범위 MP4, 전체 MP4가 동일 composition과 props를 사용한다. 기본 영상은 1920×1080 60fps H.264/yuv420p, AAC 트랙을 포함한다. 출력은 임시 파일에서 성공한 뒤 지정 경로로 이동한다. Chromium 경로와 WebGL 백엔드·동시 렌더 수를 지정할 수 있다. 최초 브라우저 준비를 제외한 렌더는 로컬에서 수행한다. 60fps 재생 규격과 실제 출력 속도는 별개다. 하드웨어가 다른 GPU의 픽셀 단위 일치는 보장하지 않는다. 관련 요구: F4, F5, N2.

## 패키징과 유지보수

npm 패키지 `disaster-broadcast-studio`, 실행명 `dbs`로 구성한다. 빌드된 JS, 지도 자산, 독립 스킬·참고자료를 포함한다. `dbs skill --out`으로 스킬 전체를 별도 워크스페이스에 복사할 수 있다. 실제 작품은 패키지나 개발 저장소에 넣지 않는다. 공개 npm 게시는 별도 승인 후 수행한다. 관련 요구: F5, F6, N3.

빠른 계약 테스트는 시간·탐색·참조·충돌·정정·페이지 보존·외부 파일 경계를 확인한다. 실제 프레임·짧은 구간·전체 영상과 외부 패키지 설치는 릴리스 경계에서 확인한다. OS별 그래픽 환경은 실제 실행 환경별로 구분해 기록한다. 스키마 변경은 실제 사용처가 생긴 뒤 영향과 변환을 판단하며 가상 호환 계층을 미리 만들지 않는다.
