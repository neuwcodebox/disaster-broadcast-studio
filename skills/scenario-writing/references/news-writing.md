# 실제 발표·뉴스의 정보 구조

확인일: 2026-11-14. 아래 자료는 사건·문장의 정보 구조를 관찰하기 위한 역사 자료다. 현재 재난 상황이나 현재 발송 기준을 뜻하지 않는다. 실제 제목, 자료 내용의 요약, 새로 쓴 허구 예문을 구별했다. 작품의 사건·반전·줄거리를 정하는 자료가 아니다.

## 1. 발생과 분석 결과가 서로 다른 시각에 나오는 지진 발표

**실제 제목:** 「경북 경주에서 규모 4.0 지진 발생」

- 발표기관·일시: 기상청, 2023-11-30 07:00.
- [공식 보도자료 본문](https://www.weather.go.kr/kma/flexer/html/press/2023/11/30/ATC202311300706423_5b92d217-f159-4590-8e79-bcae9853ff53.hwp.files/Sections1.html)
- 자료 구조: 보도시점/배포 → 발생 현황 → 통보 현황 → 위치·진도 → 관측 자료.
- 실제 경과(요약): 04:55:24 발생, 04:55:26 최초 관측, 04:55:31 자동 속보에서 추정규모 4.3, 05:00 분석사의 지진정보에서 규모 4.0, 05:07:08 추가 문자. 최종 규모가 달라져도 별개의 지진이 발생한 것은 아니다.
- 발생 시각, 관측 시각, 발표 시각, 문자 송출 시각은 서로 다르다. 한 타임스탬프에 합치면 뉴스·문자·지도 간 모순을 스스로 만들게 된다.
- 규모는 사건의 크기, 진도는 지역에서 관측되는 흔들림이다. 발표문도 규모·깊이와 지역별 최대진도를 별도 항목으로 둔다.
- 유감신고·여진 건수는 각각 기준 시각을 붙인다. 신고 건수를 피해자 수처럼 표현하지 않는다.

**같은 사건의 후속 발표:** 행정안전부 「경상북도 경주시, 규모 4.0 지진 발생(2보)」, 2023-11-30. [공식 자료](https://www.mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=105288)

후속 발표는 관측 결과를 반복하는 대신 현장상황관리관 파견 등 대응 내용을 갱신한다. `1보`, `2보`는 사건 발생 횟수가 아니라 정보 갱신이다.

**허구 헤드라인 예:** `동부 해역 지진 규모 4.1로 분석…자동 속보 4.4에서 조정`

권리 범위: 기상청·행안부 원문은 링크와 짧은 제목 인용, 사실 요약으로만 수록했다. 이 페이지 확인만으로 첨부 그림·사진의 자유 재배포를 전제하지 않는다.

## 2. 기상 현상, 위기경보, 대응체계가 별도로 발표되는 호우

**실제 제목:** 「정부, 풍수해 위기경보 '심각' 단계 발령…“인명피해 최소화 추진”」

- 발표일·출처: 2025-07-17, 행정안전부/대한민국 정책브리핑.
- [공식 정책뉴스](https://www.korea.kr/news/policyNewsView.do?newsId=148946179)
- 내용 요약: 풍수해 위기경보 상향과 중대본 3단계 가동, 근무 인원·자원 확대, 현장상황관리관 파견, 대피·통제 중심 대응을 설명한다.
- 기사 흐름: 결정된 조치 → 대응 자원과 운영 변화 → 회의·발언의 주체 → 선행강수·예상 추가 강수라는 판단 근거 → 주민 행동 당부.
- 기상청의 호우특보, 재난관리 위기경보, 중대본 대응 단계는 같은 이름의 단일 게이지가 아니다. 화면에서도 `호우경보`, `풍수해 위기경보 심각`, `중대본 3단계`를 발령 주체와 함께 구분해야 문장이 자연스럽다.
- 정책뉴스의 목표 표현과 기관장 발언은 실제 피해 감소가 확인됐다는 보도가 아니다. `최소화 추진`을 `피해 없음`으로 바꾸지 않는다.

**허구 헤드라인 예:** `풍수해 위기경보 '심각'…하천변 통제·주민 선제 대피 확대`

권리 범위: 해당 페이지는 **텍스트 공공누리 제1유형(출처표시)**을 명시한다. 사진은 뉴스1의 별도 저작권 표시가 있어 포함하지 않았다. 정책브리핑에 실렸다는 이유로 사진까지 같은 조건으로 취급하지 않는다.

## 3. 안정화에도 단계가 있는 산불 발표

**실제 제목:** 「산불 주불 진화…잔불 정리 만전」

- 출처: 대한민국 정책브리핑 사진 보도. [공식 게시물](https://www.korea.kr/multi/policyPhotoView.do?bbsKey=66487)
- 짧은 제목만 문체 참고로 인용한다. 사진은 이 자료에 수록하지 않는다.
- 함께 읽을 공식 용어 자료: [산불관리통합규정](https://www.law.go.kr/admRulLsInfoP.do?admRulId=30201&efYd=0). 현행 내용을 사용할 때 시행일을 다시 확인한다.
- 규정상 잔불은 주불 진화 뒤 남아 있는 미약한 불이며, 뒷불은 잔여 불씨가 조건에 따라 다시 발화한 것이다. `주불 진화`, `잔불 정리`, `재발화`, `완전 진화`는 서로 바꿔 쓰는 장식어가 아니다.
- 주불 진화라는 정보만으로 주민 복귀, 도로 통제 해제, 산림 출입 허용까지 자동으로 선언하면 안 된다. 그 조치가 따로 발표됐는지 구분한다.

**허구 헤드라인 예:** `남부 산불 주불 진화…야간 잔불 감시 계속` / `산불 진화 이후에도 주변 도로 통제 유지`

권리 범위: 짧은 제목과 규정 용어의 요약만 포함한다. 링크된 사진의 이용허락은 확보하지 않았으며 첨부하지 않는다.

## 4. 검사 범위와 발견 위치를 엄격히 나누는 수돗물 브리핑

**실제 제목:** 「전국 485곳 정수장 위생관리실태 특별점검 결과 발표」

- 발표자·일시: 환경부 박재현 물통합정책관, 2022-08-16.
- [공식 브리핑·질의응답 및 첨부 속기자료](https://www.korea.kr/briefing/policyBriefingView.do?newsId=156521412)
- 발표 구조: 점검 계기 → 점검 기간·기관·대상 → 공정별 발견 결과 → 즉시 조치 → 조사 결과와 추가 대책 → 기자 질문과 답변.
- 내용 요약: 원수·처리 중 공정에서의 발견과 처리가 끝난 정수에서의 발견을 나눠 보고한다. 가정까지 확산됐는지, 관련 신고가 있었는지는 또 다른 확인 항목이다.
- `정수장 27곳에서 발견` 같은 총계만 남기면 어느 공정에서 발견됐는지가 사라진다. 원수, 처리 중인 물, 정수, 가정 수돗물은 같은 관측 지점이 아니다.
- 질의응답은 원인과 책임을 묻는 질문을 포함한다. 답변자가 설명하는 조사 범위와 가능성을 그대로 구별하는 자료로 유용하다. 확정된 점검 결과와 원인 추정을 한 문장에 섞지 않는다.

**허구 헤드라인 예:** `정수장 원수에서 이물 확인…정수·가정 공급수는 검사 중`

권리 범위: 해당 페이지는 **텍스트 공공누리 제1유형(출처표시)**을 명시한다. 본 문서는 제목과 요약만 수록한다. 사진·영상·도표까지 그 조건이라고 가정하지 않는다.

## 5. 생활 기능의 연쇄 영향을 설명하는 통신장애 안내

**실제 제목:** 「방통위, 『통신장애 시 이용자 행동요령』 배포」

- 당시 발표기관: 방송통신위원회. 2019년 발표 자료이며 현재 누리집 기관명과 당시 발표기관명은 구분한다.
- [공식 게시물·행동요령 첨부](https://www.kmcc.go.kr/user.do?mode=view&page=A05030000&boardId=1113&boardSeq=47832)
- 공식 소개에서 통신장애 전·발생 시·복구 후로 단계를 나누고, 전화·인터넷뿐 아니라 카드결제·주문배달·의료 서비스의 영향까지 다룬다.
- 이를 참고하면 모든 서비스를 한꺼번에 `도시 마비`로 표현하는 대신 서비스별 확인 상태를 쓸 수 있다. 전화 복구와 결제 복구, 특정 지역 복구와 전체 복구를 구별한다.

**허구 헤드라인 예:** `서부권 인터넷 접속 장애…일부 상점 카드결제 차질` / `통신사 “음성통화 복구”…데이터 접속은 순차 정상화`

권리 범위: 짧은 제목·공식 설명 요약만 포함했다. 첨부 인포그래픽과 지침서 전문의 재배포 조건은 별도 확인 대상이며 이 문서에는 포함하지 않는다.

### 방송에 맞게 쓰기

보도는 사건·확인 상태·대응을 전하고, 재난문자는 발송기관이 대상 주민에게 행동을 요청한다. 예를 들어 허구 뉴스는 `북부권 통화장애 신고 잇따라…통신사 “복구 중”`, 문자는 `○○지역 유선전화 통화장애 복구 중입니다. 긴급상황 시 휴대전화 문자신고를 이용해 주십시오. [가상시]`처럼 역할이 다르다. 이것들은 새로 쓴 창작 예문이며 실제 발송문이나 기사가 아니다.

다음은 집필 지침이며 공식 보도 규정의 인용이 아니다. 먼저 기자가 어디에서 무엇을 취재하고, 어떤 경로로 확인했으며, 지금 보도할 필요가 무엇인지 정한다. 편집국에서 기관 발표를 정리하는 기자와 통제선 밖에 있는 현장 기자는 알 수 있는 사실과 전달 방식이 다르다. 위험 때문에 접근이 제한되거나 통신이 끊겼다면 그 제약을 보도 범위에 반영한다. 기자의 목적은 시청자에게 중요한 사실과 맥락을 전하는 것이므로, 작가만 아는 사건의 전모나 등장인물의 속마음을 기사에 넣지 않는다.

| 보도 형태 | 정보 선택과 표현 |
| --- | --- |
| 속보 | 즉시 알릴 가치가 있는 새 사실을 짧게 전달. 확인된 범위와 출처를 남기며, 정보가 적다는 이유로 추측을 채우거나 사소한 변화마다 속보를 만들지 않음 |
| 후속·일반 보도 | 확인된 경과·배경·영향·대응을 정리. 앞선 속보와 무엇이 달라졌는지 보여주며 필요한 기준 시각을 붙임 |
| 현장 연결·중계 | 기자가 관찰하거나 취재로 확인한 현장 상황을 절제해 전달. 위치·시야·안전·통신 상태의 제약을 지키고, 채팅처럼 매 순간 감탄하거나 추측을 쏟아내지 않음 |

현황판의 뉴스 항목에는 원래 보도에서 전달할 핵심을 제목·요약으로 옮긴다. 화면에 현장 영상이나 음성이 없는 상태에서 현장 연결을 하는 듯한 말투만 가져오지 않는다. ‘속보’ 표시는 장면을 긴박하게 꾸미는 장식으로 쓰지 않는다.

- 제목의 앞뒤 절이 같은 정보만 반복하지 않게 한다. 상황을 알리는 절과 새 확인·대응을 알리는 절을 조합한다.
- 제보는 제보, 신고는 신고, 대원이 직접 확인한 내용은 확인으로 쓴다. 기관의 설명에는 발언 주체를 붙인다.
- `연락 두절 신고`와 `실종 확인`, `발신 기록이 없다`와 `발신 자체가 없었다`를 바꿔 쓰지 않는다. 미확인 원인을 설명하려고 전지적 시점의 문장을 넣지 않는다.
- 실제 뉴스의 익숙한 어휘·생략 방식을 참고하되 여러 제목을 합쳐 가상의 실제 보도처럼 전재하지 않는다.
- 평상시 뉴스와 문자 문체를 구별해 두면, 나중에 뉴스가 주민에게 직접 질문하거나 문자와 같은 문구를 반복하는 의도적 변화를 관객이 알아볼 수 있다. 오류로 어색해진 문장과 의도된 매체 오염을 구분한다.

## 집필용 대조표

다음은 위 자료를 관찰해 정리한 작성 지침이지 공식 규정의 인용이 아니다.

| 작성하려는 정보 | 필요한 최소 근거 | 쉽게 생기는 과장 |
| --- | --- | --- |
| 사건 발생 | 발생·신고 시각, 장소, 정보 출처 | 신고 시각을 발생 시각으로 단정 |
| 영향 범위 | 관측/검사/장애 대상과 확인 지역 | 일부 시설의 결과를 도시 전체로 확대 |
| 피해 집계 | 집계 시각, 인명·시설의 단위 | 숫자 갱신을 모두 새 피해로 해석 |
| 대응 격상 | 결정 기관, 체계 이름, 적용 시각 | 서로 다른 단계 체계를 하나로 합침 |
| 통제·대피 | 대상 지역·구간·시설, 조치 주체 | 위험 지역의 행정구역 전체가 대피했다고 확대 |
| 원인 조사 | 조사 중/추정/확정, 발표 주체 | 기관의 가설을 기자가 확정 사실로 서술 |
| 정상화 | 어떤 기능·구간이 복구됐는지 | 일부 복구를 완전 복구로 표현 |
| 정정 | 이전 정보, 바뀐 항목, 변경 근거·시각 | 이전 정보를 기록에서 지워 변화 자체를 숨김 |

### 같은 허구 사건을 매체별로 달리 쓰는 예

아래는 전부 새로 작성한 허구이며 실제 사고나 공식 표준문안이 아니다.

- 기관 발표 제목: `서부정수장 공급계통 긴급 점검 및 대체 급수 실시`
- 뉴스 헤드라인: `서부권 3개 동 급수 중단…급수차 4대 배치`
- 뉴스 본문 첫 문장: `시 상수도사업본부는 오늘 오후 8시부터 서부권 3개 동의 수돗물 공급을 중단하고 원인을 점검하고 있다고 밝혔습니다.`
- 후속 헤드라인: `서부권 급수 재개…시 “수질검사 결과 이상 없어”`

기관 발표는 자신의 조치·설명에 초점을 두고, 뉴스는 발표 주체와 주민에게 생긴 변화를 전달한다. 재난문자는 별도의 발송 기준과 표준문안 자료를 따라 대상·행동을 직접 안내한다. 뉴스 예문을 그대로 문자로 복사하지 않는다.

## 활용과 권리 기록

- 이 파일의 요약·분석·허구 예문은 새로 작성한 설명이다. 실제 제목 외에는 원문 전재로 표시하지 않는다.
- 공공누리 허용 범위가 확인된 텍스트와, 단지 공개 열람되는 자료를 구분했다. 보도자료라는 이름만으로 모든 부속 자산의 자유이용을 가정하지 않는다.
- 허구 작품에서 실제 기관의 과거 발표를 새 사건의 발표인 것처럼 붙여 넣지 않는다. 원문은 집필 참고로, 극중 문안은 독립 창작으로 관리한다.
- 이 자료를 통해 특정 사건을 반드시 선택하거나 긴장감을 특정 반전으로 만들 필요는 없다. 서로 다른 종류의 정보가 어떤 속도·형식·확실성으로 공개되는지 참고하는 용도다.
