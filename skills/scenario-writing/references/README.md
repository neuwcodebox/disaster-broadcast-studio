# 집필 방법과 참고자료

작품의 집필·연출 방법과 제도·문안의 근거를 모은 자료집이다. 필요한 작업과 사건 유형에 따라 선택해 읽는다. 실제 작품과 집필 기록은 작품 작업공간에 보관한다.

| --- | --- |
| 작가와 역할 에이전트가 상황을 주고받으며 집필, 정보·기억·기록 관리 | [역할별 반복 롤플레잉](roleplaying.md) |
| 매체별 역할과 시청자의 관점, 정보의 시간차, 호흡·가독성·효과 | [방송 연출](direction.md) |
| 기자의 취재 범위, 속보·후속·현장 보도의 표현 | [뉴스 표현](news-writing.md) |
| 소리의 출처와 의미, Tone.js 모듈·로컬 샘플의 WAV 제작 | [음원 제작](audio.md) |

| 필요한 판단 | 자료 |
| --- | --- |
| 중앙·지방·현장 조직, 보고·지휘·대피·통제, 재난사태·특별재난지역 | [재난 대응 조직과 권한](response-system.md) |
| 침수·산불·화재·붕괴, 전력·통신·급수·정부 전산장애의 초동·복구 | [현장·생활기반 대응](field-and-infrastructure-response.md) |

## 경보·문안과 실제 사례

발송 권한과 기준을 확인한 뒤 해당 매체·상황의 문안을 고른다. 실제 사례는 정보 선택과 표현을 참고하는 역사 자료이며 현재 발령 현황이 아니다.

| 필요한 자료 | 자료 |
| --- | --- |
| 재난문자 사용기관·승인·직접 발송 기준, 기관별 문안과 후속 제도 변경 | [재난문자 발송 기준과 운영](disaster-sms-rules.md) |
| 재난 유형·기관별 90자/157자 표준문안 전체 163항목 | [재난문자 표준문안](disaster-sms-templates.md) |
| 민방위 발령·전달 체계, 사이렌·음성·TV 자막·CBS의 공식 문안 | [민방위 경보와 방송문안](civil-defense.md) |

## 자료의 판본과 적용 범위

공식 문언, 사실 요약, 새로 쓴 허구 예문을 구별한다. 법령의 시행일·고정 판본, 매뉴얼의 작성일, 실제 사례의 발생·발표일과 자료 확인일은 서로 다르다. 확인일은 모든 개정·지역별 매뉴얼까지 검증했다는 뜻이 아니다. 법정 권한, 기관의 운영 설명, 개별 사건에서 이행한 조치를 같은 수준의 규칙으로 취급하지 않는다.

재난문자는 예규 제361호(2026-02-04 시행), 민방위는 예규 제355호(2026-01-05 시행)를 기준으로 본문·표·문안을 재구성했다. 2026-05-15 재난성호우와 2026-05-28 지진현장경보 개편은 [재난문자 운영 자료](disaster-sms-rules.md#기관별-발송-체계와-후속-변경)에서 구별해 설명한다. 원문 파일 대신 각 자료에 공식 출처와 시행일을 연결했고, 병합 표와 배치용 줄바꿈을 풀어 읽을 수 있게 했다.

작품의 배경시대나 핵심 판단이 확인 범위와 다르면 해당 시기의 원천 자료를 더 확인한다. 자료의 공개 열람과 사진·지도·음원 등 부속 자산의 재사용 권리는 별개다. 참고 사례는 소재·전개·반전을 정하는 필수 구성으로 사용하지 않는다.
