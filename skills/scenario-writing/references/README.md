재난문자는 예규 제361호(2026-02-04 시행), 민방위는 예규 제355호(2026-01-05 시행)를 기준으로 본문·표·문안을 재구성했다. 기상청의 2026-05-15 재난성호우 및 2026-05-28 지진현장경보 개편은 재난문자 운영 자료의 후속 변경 절에 구분했다. 원문 파일을 중복 보관하지 않고 각 문서에 공식 출처와 시행일을 연결했다. 표의 병합 관계와 문장 선택지를 풀어 적었으며, PDF 표준문안의 열 맞춤 줄바꿈은 문장 단위로 연결했다.

공식 문언, 사실 요약, 작성자가 새로 쓴 허구 예시는 문서 안에서 구별한다. 자료를 특정 이야기나 반전의 필수 구성으로 해석하지 않는다. 배경시대가 다르면 해당 시대의 제도를 확인한다. 자료의 공개 열람 가능 여부와 사진·지도·음원 등 부속 자산의 재사용 권리는 별개다.

대응을 설계할 때는 조직·권한 자료에서 공통 구조를 읽고 사건별 자료로 이동한다. 새 대응 자료는 법률 전문집이 아니라 **누가 무엇을 판단하고 실행하며, 어떤 정보가 언제 공개되는지**를 찾는 요약이다. 법령의 시행일·고정 판본, 매뉴얼의 작성일, 실제 사례의 발생일을 구별한다. 확인일은 모든 개정·지역별 매뉴얼까지 검증했다는 뜻이 아니다. 법정 권한, 기관의 공개 운영 설명, 개별 사건의 실제 조치, 창작 적용을 나누어 읽는다.
