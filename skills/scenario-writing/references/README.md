재난문자는 예규 제361호(2026-02-04 시행), 민방위는 예규 제355호(2026-01-05 시행)를 기준으로 본문·표·문안을 재구성했다. 원문 파일을 중복 보관하지 않고 각 문서에 공식 출처와 시행일을 연결했다. 표의 병합 관계와 문장 선택지를 풀어 적었으며, PDF의 표준문안 줄바꿈은 유지했다.

공식 문언, 사실 요약, 작성자가 새로 쓴 허구 예시는 문서 안에서 구별한다. 자료를 특정 이야기나 반전의 필수 구성으로 해석하지 않는다. 배경시대가 다르면 해당 시대의 제도를 확인한다. 자료의 공개 열람 가능 여부와 사진·지도·음원 등 부속 자산의 재사용 권리는 별개다.
