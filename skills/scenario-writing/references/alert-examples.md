# 실제 발송 재난문자 사례

확인일: 2026-11-15. 행정안전부 재난안전데이터공유플랫폼의 **개별 상세 기록 20건**을 직접 대조한 역사 사례다. 창작 문안이나 표준문안이 아니며, 현재 발령 현황·현행 발송 기준을 대신하지 않는다. 법정 표준문안은 [표준문안집](disaster-sms-templates.md), 사용기관·등급·발송 절차는 [문자 운영](disaster-sms-rules.md)에 있다.

## 읽는 방법

- 시각은 출처 페이지의 **등록일**이다. 본문 속 사건 발생·발효·작업 예정 시각, 실제 휴대전화의 수신 시각과 구별한다. 등록일을 송출·수신 시각으로 확정하지 않는다.
- 기관은 본문의 발신 표기를 따른다. 상세페이지의 지역 표기만으로 기지국 송출 범위·등급·명령권자를 추정하지 않는다.
- **전문**은 해당 기록의 문자 본문 전체, **발췌**는 그 안의 연속된 짧은 부분이다. 띄어쓰기·상호·지명·당시 기관명·표현을 고치지 않았다. 생략한 발신 표기는 메타데이터에서 확인한다.
- 인용은 문체·정보 구조를 관찰하기 위한 짧은 범위다. 자료의 이용조건은 출처별로 확인한다. [긴급재난문자 데이터셋](https://www.data.go.kr/data/15134001/openapi.do)은 공공누리 제4유형을 표시하므로, 공개 데이터라는 이유로 대량 복제·수정·상업적 재배포 권한을 전제하지 않는다. 작품 문안은 해당 배경·기관·위험에 맞게 별도로 작성한다.

찾을 내용: 예방 / 발생·통제 / 지진 초동·후속 / 계획 단수 / 복구·재개 / 화학사고 초기·후속 / 방류 / 폭염 / 해제 / 민방위 훈련 / 군사 관련 위험.

## 원인을 모르는 사건에 적용하기

이 사례의 물질명·명령·발송 등급을 원인불명 사건에 그대로 옮기지 않는다. [보건·유해물질 대응](health-and-hazard-response.md)에서 조사·확인의 범위를 확인하고, 기관이 실제로 확인한 위험·대상·필요 행동을 [문자 운영](disaster-sms-rules.md)의 발송 절차에 맞춰 새로 작성한다. 확인된 특정 현장 접근 자제와 도시 전체 대피, 권고와 법적 명령은 [대응 조직과 권한](response-system.md)에서 구별한다.

실제 전쟁·화생방공격이 확인된 사례가 아닌 훈련·풍선 문자까지 공격 발령 사례로 분류하지 않는다. 공격에 대한 발령·전달 문안은 [민방위 규정](civil-defense.md), 판단·대응 주체는 [화생방·테러 대응](cbrn-and-terror-response.md)에서 확인한다. 실제 사례가 부족한 유형은 공식 표준문안과 창작 문안으로 구분해 보완하며, 새로 만든 문장을 실제 발송 사례처럼 소개하지 않는다.
