# 감염병·화학사고·방사선비상의 대응

확인일: 2026-11-15. 공식 법령·기관 지침을 창작을 위해 요약했다. 사건의 원인이 불명확할 때 어떤 기관이 무엇을 확인하고 주민에게 무엇을 알리는지 찾는 자료다. 실제 현장의 진료·방제·방사선방호를 지휘하는 매뉴얼이 아니다. 아래 **사실 요약**과 **창작 적용**을 구별한다.

## 사건에 맞는 자료 찾기

| 작품에서 필요한 장면 | 먼저 확인할 항목 |
| --- | --- |
| 여러 사람이 같은 이상 증상으로 이송됨 | 신고·환자 집계·감염 가능성·공동 노출과 원인불명 질병 조사 |
| 병원·보건소가 검사하거나 격리함 | 질환별 신고 범위와 검사·입원·격리의 법적 요건 |
| 공장·운반차량 주변의 이상 기체·냄새 | 화학사고 신고·물질 확인·확산평가·주민보호 조치 |
| 원전 이상·방사능 측정·주민 대피 | 방사선비상 분류, 방사능재난 선포, 주민보호 결정의 구별 |

본부의 일반 관계는 [재난 대응 체계](response-system.md), 경보 명칭은 [상황 지표](status-systems.md), 문자 발송은 [재난문자 운영](disaster-sms-rules.md)을 함께 본다. 전문기관의 내부 보고가 곧 공개 방송의 수신 정보는 아니다.

## 1. 집단 이상 증상과 감염병

### 법률상 조사와 강제조치는 구별한다

**사실 요약.** [「감염병의 예방 및 관리에 관한 법률」 2026-10-08 시행본](https://www.law.go.kr/LSW/lsInfoP.do?efYd=20261008&lsiSeq=285325), 법률 제21521호(2026-04-07 일부개정)를 기준으로 확인했다.

| 근거 | 무엇을 할 수 있는가 | 집필에서 구별할 점 |
| --- | --- | --- |
| 제11·13조 | 의료인의 신고, 보건소를 통한 보고 | 신고 대상·기한·의사환자 포함 여부는 감염병 분류와 지침에 따름. 신고 건수가 곧 확진자 수는 아님 |
| 제18·18조의2 | 질병관리청장·시도지사·시장·군수·구청장의 역학조사, 의료인·의료기관장의 조사 요청 | 감염병 여부가 불분명해도 발병원인 조사 필요성이 인정되면 조사 가능 |
| 제41조 | 정해진 감염병·대상자에 대한 입원·자가·시설치료 등의 관리 | 아무 증상이나 ‘강제 격리’의 근거가 되지는 않음 |
| 제47조 | 유행 시 오염 장소 폐쇄·출입금지·해당 장소 내 이동제한, 의심자 입원·격리 등 | 장소·대상·전파 방지 목적을 특정. 건물 폐쇄와 도시 전체 통제는 다름 |
| 제49조 | 감염병 예방을 위한 교통 차단·집합 제한 등 | 조치별 권한·요건 확인. 복지부장관에게 허용한 조치의 범위도 별도로 규정됨 |
| 제34조의2 | 주의 이상 위기경보 시 예방에 필요한 정보 공개 | 예방과 관계없는 개인정보 제외, 목적이 사라진 공개정보 삭제·이의신청 규정도 있음 |

조사 착수의 근거는 [제18조 조문](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027567911), 예방조치는 [제49조 조문](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029392537)을 대조할 수 있다. 특정 조치에 필요한 감염병 지정·시행령·고시·개별 명령은 작품의 배경시대에서 다시 확인한다.

### 원인을 모르는 때에도 대응 절차가 있다

**사실 요약.** 질병관리청 [「원인불명 질병 집단감염 대응지침」 제3판](https://www.kdca.go.kr/bbs/kdca/55/260068/download.do), 2024년 판, 게시 2024-12-23·최종수정 2024-12-24를 확인했다. 이하 쪽수는 PDF 뷰어 번호가 아닌 책자 인쇄 쪽수다.

| 인지·판단 | 지침에서 확인할 대응 |
| --- | --- |
| 감염이 의심되는 원인불명 중증·사망 집단발생, 의료인의 조사 요청 | 사실관계 확인·기초역학조사부터 시작(3~6쪽, 14~16쪽) |
| 최초 인지 보건소 | 초기 대응, 필요시 환자·검체 이송과 현장 방역, 접촉자 조사·관리(4쪽) |
| 시도·권역 질병대응센터·질병관리청 | 사례 해당 여부 검토, 상황판단과 지원·역학조사 주관 조정(5쪽, 17~18쪽) |
| 긴급상황 | 합동 평가 또는 중앙역학조사반 긴급 파견이 가능. 모든 회의를 차례로 끝낼 때까지 대기하는 구조가 아님(17쪽) |
| 감염성 원인이 아닌 것으로 판단됨 | 관계 부처·기관으로 이관하거나 담당 부서 변경(4쪽) |

이 지침은 화학물질·방사선처럼 **감염병 외 원인이 명백히 우선 의심되는 경우**에는 적용을 제외한다. 이상 증상이 여러 명에게 생겼다는 사실만으로 새로운 감염병임을 확정하지 않는다. 2024년 판의 내부 부서명을 2026년 조직명으로 자동 간주하지 않는다.

증상·검체 채취·진단·신고·검사 결과·감염원 판단은 서로 다른 정보다. 질병관리청 [2026년도 호흡기감염병 관리지침](https://www.kdca.go.kr/bbs/kdca/55/306134/download.do) 34쪽은 유행 인지 경로, 기초자료 수집, 시간·장소·사람·특성에 따른 사례정의를 구분하고 조사 중 정의를 수정할 수 있음을 설명한다. 해당 질환군의 절차이며 모든 감염병의 전국 공통 수치 기준으로 쓰지 않는다.

### 창작 적용: 발표가 바뀌는 이유를 남긴다

다음은 지침의 법정 서식이나 실제 사건 인용이 아닌 집필용 판단이다.

- `같은 시설 이용자 중 이상 증상 신고` → `보건당국 조사 착수` → `검체 검사·공동 노출 조사` → `확인한 원인과 조치`처럼 **그때 확인된 사실**을 갱신한다. 모든 장면에 같은 순서나 고정 분 간격을 강제하지 않는다.
- 구급차로 이송한 인원, 의료기관 진료 인원, 조사대상자, 확진자는 같은 집계가 아니다. 기관의 집계 기준·기준시각을 붙인다.
- 검사 중에는 병원체·전파 방식·잠복기를 작가가 확정해 기관 발표에 넣지 않는다. 특정 검사 음성도 모든 감염성 원인 배제를 뜻하지 않는다.
- 시설 이용 자제 요청, 감염병법상 장소 폐쇄, 환자 격리, 경찰의 현장 통제를 각각 누가 어떤 근거로 시행하는지 정한다.
- 개인정보를 포함한 내부 접촉자 명단을 현황판에 그대로 노출하지 않는다. 공개 브리핑과 주민에게 필요한 행동 안내를 선택한다.

## 2. 유해화학물질 누출과 화학사고

### 사업자 신고와 여러 기관의 현장 역할

**사실 요약.** [「화학물질관리법」 2026-10-08 시행본](https://www.law.go.kr/LSW/lsInfoP.do?efYd=20261008&lsiSeq=285367), 법률 제21531호(2026-04-07 일부개정)의 제43~45조를 기준으로 한다.

- 제43조는 취급자의 응급조치, 중대성·시급성이 인정될 때 가동 중단, 사고 발생 시 관계기관에 대한 즉시 신고를 정한다. 사업자의 자체 점검이 끝나야 신고할 수 있는 절차가 아니다.
- 제44조의 현장수습조정관은 기후에너지환경부장관이 파견할 수 있으며 조정·지원·기관 협조와 대국민 브리핑 등을 맡는다. 모든 사고에 반드시 같은 시각 파견되는 것은 아니다.
- 제44조의2의 가동중지명령과 제45조의 사고 영향조사는 초동 구조·주민보호와 구별한다. 누출이 멎었다는 사실만으로 건강·환경 영향조사가 끝나지 않는다.

[제43조 신고·응급조치](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029309605), [제44조 현장수습조정관](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1021095727)을 확인할 수 있다.

화학물질안전원 [화학사고대응 개요](https://nics.mcee.go.kr/sub.do?menuId=14)는 아래 역할을 제시한다. 웹페이지의 자체 개정일은 표시되지 않아 확인일 기준이며, 법적 지휘권 전체를 정한 조직도는 아니다.

| 주체 | 공개 설명에서 확인되는 역할 |
| --- | --- |
| 최초 발견자·사업장 안전관리자 | 사고 인지·신고, 현장 응급조치·상황보고 |
| 소방 | 화학구조·구급 전문요원 출동, 긴급구조와 현장 대응 |
| 화학물질안전원 | 유관기관 전파, 사고물질 방제정보·피해범위 예측·확산평가 정보 제공 |
| 유역·지방환경청·화학재난합동방재센터 | 안전원과 협업, 오염확산 방지·방제 등 |
| 지자체 | 주민 피난 유도·보호, 사후 복구 등 |
| 경찰 | 차량·주민 접근 통제 |

### 실내대피와 외부 이동은 조건에 따라 다르다

**사실 요약.** [국민안전24 화학사고재난 행동요령](https://safekorea.go.kr/safekorea-kor/acts/nacts/action-guide.do?actsHeaderTitle=%ED%99%94%ED%95%99%EC%82%AC%EA%B3%A0%EC%9E%AC%EB%82%9C&category=chemicalAccidentDisaster&menuSn=4)은 발견 시 안전한 곳에서 119 신고, 주민 알림 수신 시 지정 대피 안내가 없으면 실내에서 추가 정보 확인, 위치와 풍향에 따른 노출 회피를 구분한다. 실내에서는 출입문·창문을 닫고 외부 공기 유입을 줄이며 환기설비를 중단하도록 안내한다. 모든 물질에 같은 이동 방향·높이가 적합하다는 뜻은 아니다.

### 창작 적용: 냄새·확산예측·측정값을 구별한다

다음은 창작을 위한 적용이며 표준문안 전재가 아니다.

- 초기 신고의 냄새·색·증상은 관찰 정보다. 그것만으로 물질명·농도·독성을 확정하지 않는다.
- 사업자 취급물질 확인, 현장 탐지, 검체 분석, 풍향·기상 기반 확산평가는 다른 출처다. 예측 영향범위와 실제 오염 확인 지역을 지도에서 구별한다.
- `인근 주민 창문 닫고 실내 대기`와 `특정 구역 주민 지정 장소로 이동`은 모순이 아닐 수 있다. 위치·풍향·발령시각·안전한 이동로가 달라졌는지 기록한다.
- 재난문자는 기관의 행동 지시를 전달하고, 뉴스는 누출·구조·통제·분석을 출처와 함께 보도한다. 환경당국이 조사 중이라는 이유로 소방 구조가 정지된 것으로 쓰지 않는다.
- 환경부 명칭으로 작성된 과거 문서를 현재 작품에 쓸 때 기관 개편을 확인한다. 이 확인일의 법령·안전원 누리집은 **기후에너지환경부** 명칭을 사용한다.

## 3. 원자력시설의 방사선비상

### 비상 색과 주민 대피는 같은 정보가 아니다

**사실 요약.** [「원자력시설 등의 방호 및 방사능 방재 대책법」 2026-01-01 시행본](https://www.law.go.kr/LSW/lsInfoP.do?efYd=20260101&lsiSeq=268613), 법률 제20720호(2025-01-21 일부개정)와 [시행령 별표 3](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=159250779&gubun=)(표에 표시된 개정일 2021-12-23)을 확인했다. 별표 원문의 개정일과 법률 시행일은 서로 다르다. 2027-04-01 시행 예정 개정본을 이 기준에 섞지 않는다.

| 종류 | 별표가 구별하는 예상 영향 범위 |
| --- | --- |
| 백색비상 | 방사선영향이 원자력시설 건물 안에 국한될 것으로 예상 |
| 청색비상 | 주요 안전기능의 손상 또는 그 우려 등으로 영향이 부지 안에 국한될 것으로 예상 |
| 적색비상 | 최후방벽 손상 또는 그 우려 등으로 영향이 부지 밖에 미칠 것으로 예상 |

이는 측정값만 확인된 뒤 발령하는 분류가 아니다. 누출·손상 **우려와 예상 영향**도 포함하며, 적색 발령 자체가 주변 모든 주민의 피폭 확인이나 전국 대피 명령을 뜻하지 않는다.

### 보고·지휘·주민보호·공개 창구

**사실 요약.** 같은 법 제20~21·23~30·34·35조의2에서 구별하는 사항이다.

| 주체·장치 | 역할과 구별 |
| --- | --- |
| 원자력사업자 | 승인된 방사선비상계획에 따른 보고·응급조치·관련 정보 공개 |
| 원자력안전위원회 | 관련기관 통보, 방사능재난 선포, 중앙방사능방재대책본부와 현장지휘 체계 |
| 지역방사능방재대책본부 | 관할 지자체 단체장이 본부장. 주민보호 결정사항 시행 |
| 현장방사능방재지휘센터장·합동협의회 | 주민보호 조치를 결정하며 제30조에 따라 합동방재대책협의회 의견을 듣는 절차 |
| 연합정보센터 | 정확하고 통일적인 재난정보 제공. 현장지휘센터 운영 전에는 원안위에 운영 |

제29조의 주민보호 결정에는 대피·소개·음식물 섭취 제한·갑상샘방호약품 배포와 복용지시 등이 있다. 방사선비상, 제23조의 방사능재난 선포, 개별 주민보호 조치를 같은 ‘경보’ 한 줄로 합치지 않는다. 제34조는 이 특별법의 중앙·지역본부를 기본법의 중대본·지대본으로 본다. 별도 본부들을 기계적으로 추가해 중복 명령계통을 만들지 않는다.

갑상샘방호약품은 제35조의2에 따라 원안위와 협의한 특정 지역·연령 등에 사전 배포할 수도 있다. **수령과 복용은 별개**다. [울산 남구의 복용 안내](https://www.ulsannamgu.go.kr/fieldInfo/radiationPrevention/radiationPrevention03.jsp)(2026-01-23 갱신)는 정부 복용지시 때 복용하고 추가 지시 때만 반복하도록 안내한다. 이 약을 모든 방사선 피해의 예방·치료약처럼 쓰거나 비상 색만 보고 임의 복용시키지 않는다. 지역별 배포장소·용량은 작품 장면에 필요할 때 해당 계획을 확인한다.

### 창작 적용: 구역과 공개 정보의 범위를 맞춘다

다음은 집필용 판단이며 실제 사고 대응을 예측하는 시간표가 아니다.

- 사업자 설비 이상 보고, 비상 발령, 환경방사선 측정, 영향평가, 주민보호 조치, 피해 집계의 발표시각을 구별한다.
- 방사선비상계획구역은 사전에 대비를 집중하는 구역이다. 그 전체가 현재 오염되었다는 지도 표시는 하지 않는다. 실제 소개·대피 대상은 극중 발표한 범위로 지정한다.
- 운영정지·외부 전원 상실·배출·방사선량 상승은 서로 다른 사실이다. 비상 단계만으로 노심 손상이나 실제 방출을 기자가 확정하지 않는다.
- 현황판은 공개된 사업자 발표·원안위 브리핑·지자체 행동 안내를 수신한다. 실시간 원자로 내부 수치나 대책회의 내용을 임의로 알고 있지 않는다.
- 식품·물·농수산물 제한과 주민 귀환은 각 조치의 대상·해제 발표를 따로 갱신한다. 경보가 낮아졌다는 이유만으로 모두 정상화한 것으로 쓰지 않는다.

## 출처를 작품에 적용할 때

이 문서는 조사한 법령과 공개 자료의 사실을 요약하고, 창작 판단은 별도로 작성했다. 특정 사건을 의무적인 줄거리로 삼지 않는다. 법률은 권한의 근거, 지침은 해당 질환·사고의 실무 절차, 주민 행동요령은 수신자 안내라는 용도를 유지한다. 기관 웹페이지의 사진·그림·음원 이용권은 별도이며 링크한 자료를 실제 새 사건의 공식 발표처럼 전재하지 않는다.
