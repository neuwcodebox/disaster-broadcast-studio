# 재난문자 표준문안

행정안전부예규 제361호(2026-02-04 시행), 별표 2 「휴대전화 재난문자방송 표준문안(제10조 관련)」의 전체 163항목이다. 표의 병합 셀은 각 항목의 분류·주관기관·유형으로 풀어 적고, 90자·157자 문안이 함께 있는 항목은 둘 다 보존했다. 문안 내부의 원문 줄바꿈은 유지한다.

출처: [규정 판본](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000274384) · [별표 2 원문 PDF, 18쪽](https://www.law.go.kr/LSW/flDownload.do?flSeq=161769011&bylClsCd=200201). 해당 판본 페이지의 별표 링크와 연결 확인. 확인일: 2026-11-14.

이 문안들은 실제 표준문안이며 창작 예시가 아니다. 작품에 사용할 때는 해당 상황·기관·지역을 구분한다. 원문의 90자·157자 표시는 이 별표의 서식 구분이며 모든 시대와 채널의 보편 한도로 확대하지 않는다.
